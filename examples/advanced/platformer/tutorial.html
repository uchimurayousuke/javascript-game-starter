横スクロールのジャンプアクション

上級者向け

変数、関数、配列、if 文、for 文、キー入力と基本の当たり判定を知っている人向けです。これまでの知識を組み合わせ、クラス、重力、地形との衝突、長いステージとカメラを学びます。クラスはこの教材で初めて説明します。

左右の矢印キーで移動し、Space または上の矢印キーでジャンプします。コインを集め、赤い敵とすき間を避けて紫色のゴールへ進みます。失敗やクリアの後は R キーで再挑戦できます。キーボードを使えるパソコンで遊んでください。

完成版で遊ぶ

コードの比較の読み方

比較欄では消す行、追加する行、そのままの行を色とラベルで示します。長い比較では変更のない途中の行を省略することがあります。比較欄は読むためのもので、選択してコピーする欄ではありません。

− 消す＋ 追加そのまま

「置き換える」場合は、赤い行だけを消すのではなく、指定された変更前の範囲すべてをコピー用のコード全体に置き換えます。そのままの行もコピー用のコードに含まれます。古い関数を残して同じ名前の関数を追加しないでください。「追加する」場合は、指定された場所にコピー用のコードを加えます。

コピーするのは「コピー用」と書かれたコード欄です。比較欄のラベルや記号はコードに入りません。全文の見本は手元のコードを見比べるための参考です。

ステップ 1：プレイヤーと地面を描く

目標：Player クラスを使って青いプレイヤーと緑の地面を描きます。

次は説明用の抜粋です。編集にはこの後の「比較とコピー用コード」を開いて使います。

プレイヤーの形と初期値を決める

プレイヤーの位置と大きさを一人分にまとめます。

class Player {
  constructor() {
    this.x = 80;
    this.y = 350;
    this.width = 30;
    this.height = 40;
  }

class Player はプレイヤーのデータと動作の形を決めます。constructor() は実体を作るときの初期設定です。this は今作っている実体を指し、その x と y に左上の位置、width と height に幅30と高さ40を入れます。このように実体が持つ値をプロパティと呼びます。画面は左上が (0, 0) で、右へ行くほど x、下へ行くほど y が大きくなります。

プレイヤーを作る

ゲームの開始時に一人分の実体を用意します。

player = new Player();

new Player() はクラスから実体を作り、constructor() を呼びます。この実体をインスタンスと呼び、変数 player に入れます。

プレイヤーと地面を描く

地面を描いてから、プレイヤー自身の描画を呼びます。

ctx.fillStyle = "#7cb97a";
ctx.fillRect(0, 390, 800, 60);
player.draw();

fillStyle は塗る色、fillRect の4つの値は左上の x・y と幅・高さです。地面の上端は y=390。プレイヤーの上端350に高さ40を足すと390なので、足元が地面に接します。player.draw() はクラス内の draw() を呼び、その実体の位置と大きさで青い四角を描きます。クラス内の動作をメソッドと呼びます。

更新と描画を繰り返す

ゲームループが次の画面を予約します。

update();
draw();
requestAnimationFrame(gameLoop);

start() は開始時の設定、update() は毎回の動きと判定、draw() は描画を担当します。この段階の update() は空です。gameLoop() は更新と描画を順に呼び、requestAnimationFrame() で次の更新を予約します。再挑戦では動いているループを増やさず、状態を戻して続けます。

ステップ 2：移動とジャンプ・重力

目標：Player に移動とジャンプのメソッドを加えます。

次は説明用の抜粋です。編集にはこの後の「比較とコピー用コード」を開いて使います。

キーを覚える

押した方向とジャンプの押し始めを記録します。

if (event.code === "ArrowLeft") left = true;
if (event.code === "ArrowRight") right = true;
if ((event.code === "Space" || event.code === "ArrowUp") && !jumpHeld) {
  jumpHeld = true;
  jumpPressed = true;
}

event.code でキーを調べ、左右は押すと true、離すと false にします。Space または上キーを押したとき、jumpHeld が false なら押し始めとして jumpPressed を立てます。離すと jumpHeld を戻すため、押し続けても新たなジャンプ入力になりません。別のタブへ移る blur でも入力を消します。

左右へ動かす

押されている方向へ位置を変え、画面の端で止めます。

if (left) this.x -= 4;
if (right) this.x += 4;
this.x = Math.max(0, Math.min(canvas.width - this.width, this.x));

1回の更新で左なら x を4減らし、右なら4増やします。Math.min で右端を画面幅からプレイヤーの幅を引いた位置までに制限し、Math.max で左端を0以上にします。両方を押すと増減が打ち消されます。

ジャンプと重力

地面にいるときだけ上向きの速さを与えます。

if (jumpPressed && this.onGround) {
  this.vy = -11;
  this.onGround = false;
}
jumpPressed = false;
this.vy = Math.min(this.vy + 0.5, 12);
this.y += this.vy;

&& の両方が成り立つとき、縦の速さ vy を -11 にします。y は下へ増えるので負の速さは上向きです。入力を使った後は jumpPressed を戻します。毎回0.5を足す重力で上向きの速さが減り、やがて下向きになります。Math.min は落下速度を最大12に抑え、最後に速さを y に足します。

地面に着地する

足元が地面に届いたら、めり込まない位置へ戻します。

if (this.y + this.height >= 390) {
  this.y = 390 - this.height;
  this.vy = 0;
  this.onGround = true;
}

this.y + this.height は足元の位置、390は地面の上端です。足元が390以上なら上端を 390 - 高さ にして速度を0にし、着地中を表す onGround を true にします。外側の update() が player.update() を呼び、この処理を繰り返します。

"use strict";

const canvas = document.querySelector("#game-canvas");
const ctx = canvas.getContext("2d");

let player;
let left = false, right = false, jumpHeld = false, jumpPressed = false;

class Player {
  constructor() {
    this.x = 80;
    this.y = 350;
    this.width = 30;
    this.height = 40;
    this.vy = 0;
    this.onGround = false;
  }

  update() {
    if (left) this.x -= 4;
    if (right) this.x += 4;
    this.x = Math.max(0, Math.min(canvas.width - this.width, this.x));
    if (jumpPressed && this.onGround) {
      this.vy = -11;
      this.onGround = false;
    }
    jumpPressed = false;
    this.vy = Math.min(this.vy + 0.5, 12);
    this.y += this.vy;
    if (this.y + this.height >= 390) {
      this.y = 390 - this.height;
      this.vy = 0;
      this.onGround = true;
    }
  }

  draw() {
    ctx.fillStyle = "#2765b0";
    ctx.fillRect(this.x, this.y, this.width, this.height);
  }
}

地形を並べる

地面や壁を四角形の配列に入れます。

四角の重なりを調べる

左右と上下の端を比べます。

return a.x < b.x + b.width && a.x + a.width > b.x &&
       a.y < b.y + b.height && a.y + a.height > b.y;

a.x は一方の左端、a.x + a.width は右端です。互いの左右と上下がすべて重なると true を返します。端がぴったり接するだけでは重なりません。

横に動かし壁に戻す

左右の入力から移動量を決めて衝突を調べます。

const dx = (right ? 4 : 0) - (left ? 4 : 0);
this.x += dx;
for (const block of terrain) {
  if (overlaps(this, block)) {
    if (dx > 0) this.x = block.x - this.width;
    if (dx < 0) this.x = block.x + block.width;
  }
}

条件 ? A : B は条件が正しければ A、そうでなければ B を選びます。右入力なら4、左入力なら4を引くので、両方なら dx は0です。右へ動いて重なれば、壁の左端から幅を引いた位置に戻します。幅30で壁の左端が300なら、左端は270です。左向きなら壁の右端に戻します。

縦に動かし着地や頭の衝突を調べる

重力で縦に動かしてから、地形との重なりを調べます。

this.y += this.vy;
this.onGround = false;

  if (overlaps(this, block)) {

      this.y = block.y - this.height;

下向きなら足元を地形の上端にそろえ、onGround を true にします。床の上端390から高さ40を引くとプレイヤーの上端は350です。上向きなら頭を地形の下端にそろえます。どちらも縦速度を0にします。横と縦を別々に判定するので、壁にぶつかったときに着地と間違えにくくなります。

状態とゴールを用意する

ゴールの位置とゲームの状態を持ちます。

goal は左上が (2300, 310)、幅35、高さ80の四角です。state は playing、over、clear のいずれかを表し、start() で playing にします。

失敗とクリアを判定する

落下や敵への接触を先に調べ、その後にゴールを調べます。

if (player.y > canvas.height) state = "over";
for (const enemy of enemies) {
  if (overlaps(player, enemy)) state = "over";
}
if (state === "playing" && overlaps(player, goal)) state = "clear";

画面下に落ちるか敵と重なると over です。まだ playing でゴールと重なれば clear にします。同時に敵とゴールに触れた場合は先に失敗になり、クリアにはなりません。

終了後の更新を止める

プレイ中以外は動きや判定を進めません。

if (state !== "playing") return;
