fits は図形のある各マスが盤面内で空いているか調べます。every はすべてのマスが条件を満たすとき真を返し、!value の空の部分は判定から除きます。

動ける位置か調べて移動する

Game の constructor の後に追加します。

目印

    this.state = "playing"; this.counter = 0; this.score = 0; this.lines = 0;
  }

追加するコード

  move(dx, dy) {
    if (this.state !== "playing") return false;
    if (this.board.fits(this.piece, this.piece.x + dx, this.piece.y + dy)) {
      this.piece.x += dx; this.piece.y += dy; return true;

dx と dy は横と縦の移動量です。移動先が空いていれば位置を変えて true、動けなければ false を返します。

  if (game.state !== "playing") return;
  game.counter++;
  if (game.counter >= 30) { game.counter = 0; game.move(0, 1); }
}

プレイ中は counter を1ずつ増やします。30以上になったら0に戻し、縦に1マス動かします。30秒ではなく、30回の更新です。

Piece の draw() を閉じる次の範囲の後に追加します。

  }

追加するコード

  rotated() {
    return this.shape[0].map((_, x) => this.shape.map(row => row[x]).reverse());
  }

各列を取り出して逆順に並べ、右へ90度回した形を返します。たとえば [[1,0],[1,1]] は [[1,1],[1,0]] になります。元の図形はここでは変更しません。

置けるときだけ回転を反映する

Game の move() を閉じる次の範囲の後に追加します。

目印

    return false;
  }

追加するコード

  rotate() {
    const shape = this.piece.rotated();
    if (this.board.fits(this.piece, this.piece.x, this.piece.y, shape)) this.piece.shape = shape;
  }

rotated() で回転後の形を作り、fits() で置けるときだけ現在の形に入れます。壁や積んだマスに重なる場合は回転しません。

このステップの見本を図で見る

目標

書く場所と置き換えるコード

そろった行を消す

Board の lock() の後に追加します。

目印

    piece.shape.forEach((row, dy) => row.forEach((value, dx) => { if (value) this.cells[piece.y + dy][piece.x + dx] = 1; }));
  }

追加するコード

  clearRows() {
    const kept = this.cells.filter(row => row.some(cell => !cell));
    const cleared = 14 - kept.length;
    while (kept.length < 14) kept.unshift(Array(8).fill(0));
    this.cells = kept;
    return cleared;
  }

空きマスがある行だけを残し、元の14行との差から消した行数を求めます。上に空の行を補い、消した行数を返します。

      const count = this.board.clearRows(); this.lines += count; this.score += count * 100;

消した行数を lines に足し、1行100点を得点に加えます。合計2行以上ならクリアにします。
