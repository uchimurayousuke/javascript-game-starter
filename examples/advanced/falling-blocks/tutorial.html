以前の比較の読み方

コードの比較の読み方

比較欄では消す行、追加する行、そのままの行を色とラベルで示します。変更のない途中の行を省略することがあります。比較欄は読むためのもので、コピーする欄ではありません。

− 消す＋ 追加そのまま

置き換えるときは、赤い行だけを消すのではなく、指定された変更前の範囲すべてをコピー用のコードに置き換えます。そのままの行もコピー用のコードに含まれます。古い関数を残して同じ名前の関数を追加しないでください。

コピーするのは「コピー用」と書かれたコード欄です。比較の記号はコードに入りません。

  move(dx, dy) {
    if (this.state !== "playing") return false;
    if (this.board.fits(this.piece, this.piece.x + dx, this.piece.y + dy)) {

  if (game.state !== "playing") return;
  if (["ArrowLeft", "ArrowRight", "ArrowDown", "ArrowUp", " "].includes(event.key)) event.preventDefault();
  if (event.key === "ArrowLeft") game.move(-1, 0);
  else if (event.key === "ArrowRight") game.move(1, 0);
  else if (event.key === "ArrowDown") game.move(0, 1);
  else if (event.key === "ArrowUp") game.rotate();
});

function gameLoop() {
  update();
  draw();
  requestAnimationFrame(gameLoop);
}

start();
gameLoop();
