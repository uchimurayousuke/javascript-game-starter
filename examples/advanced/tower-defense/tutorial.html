コードの意味

start() は始めるときの設定、update() は毎回の動きや判定、draw() は画面の描画です。gameLoop() は update() と draw() を順に呼び、requestAnimationFrame() で次の更新を予約します。再挑戦では動いているゲームループを増やさず、状態を戻して続けます。

道の始点に「入口」、終点に「ゴール」と表示します。敵は入口からゴールへ進みます。

class Enemy は敵の設計図です。new Enemy() が呼ぶ constructor() は、その敵自身の this.x、this.y、体力、次の経路点を初期化します。複数作れば、それぞれ別々の位置と体力を持ちます。

設計図から別々の実体を作る流れは脱出ゲームの図でも確認できます。図は本棚と引き出しの例です。

path は(100,300)、(300,300)、(300,100)、(700,100)の順にたどる点です。nextPoint は次の目標の番号です。敵の update() が毎回、目標との差 dx と dy を計算します。

Math.hypot(dx, dy) は2点間の距離です。距離が2以下なら目標にぴったり置いて次の点を選び、それ以外は方向を距離で割って2ピクセル進めます。最後の点に着くと reached が true になります。

enemy.update() と enemy.draw() は配列の各実体のメソッドです。その呼び出しの this はそれぞれの敵自身を指します。

"use strict";

const canvas = document.querySelector("#game-canvas");
const ctx = canvas.getContext("2d");

const path = [{x: 100, y: 300}, {x: 300, y: 300}, {x: 300, y: 100}, {x: 700, y: 100}];

class Enemy {
  constructor() {
    this.x = path[0].x;
    this.y = path[0].y;
    this.nextPoint = 1;
    this.hp = 2;
    this.alive = true;
    this.reached = false;
  }

  update() {
    if (!this.alive) return;
    const target = path[this.nextPoint];
    const dx = target.x - this.x;
    const dy = target.y - this.y;
    const distance = Math.hypot(dx, dy);
    if (distance <= 2) {
      this.x = target.x;
      this.y = target.y;
      this.nextPoint++;
      if (this.nextPoint === path.length) {
        this.reached = true;
        this.alive = false;
      }
    } else {
      this.x += dx / distance * 2;
      this.y += dy / distance * 2;
    }
  }

  draw() {
    ctx.fillStyle = "#db6258";
    ctx.fillRect(this.x - 12, this.y - 12, 24, 24);
  }
}

let enemies;

function start() {
  enemies = [new Enemy()];
}

function update() {
  for (const enemy of enemies) enemy.update();
}

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "#d9c8a4";
  ctx.fillRect(100, 285, 200, 30);
  ctx.fillRect(285, 100, 30, 200);
  ctx.fillRect(300, 85, 400, 30);
  ctx.fillStyle = "#24354a";
  ctx.font = "18px sans-serif";
  ctx.fillText("入口", 80, 345);
  ctx.fillText("ゴール", 670, 70);
  for (const enemy of enemies) if (enemy.alive) enemy.draw();
  ctx.fillStyle = "#24354a";
  ctx.font = "21px sans-serif";
  ctx.fillText("敵が道の点を順に進みます", 100, 45);
}

function gameLoop() {
  update();
  draw();
  requestAnimationFrame(gameLoop);
}

gameLoop();

class Bullet は弾の設計図です。発射時に new Bullet(this.x, this.y, enemy) とし、位置と目標の敵を弾自身の this に保存します。

Bullet.update() は現在の敵の位置を目指します。距離が8以下なら飛び越さずに命中させ、体力を1減らして active = false にします。そうでなければ方向に8ピクセル進みます。

すでに目標の敵が倒れていれば弾を消します。filter(bullet => bullet.active) は有効な弾だけを残すので、同じ弾が何度も命中しません。

コードの意味

wave は画面の「敵の集団」、lives は「拠点の残り」です。拠点の残りが0になると失敗します。

wave は現在の波、spawned はその波で出した敵の数です。40更新後に最初の敵を出し、80更新ごとに合計3体出します。全員いなくなれば次の波まで90更新待ち、3波を守りきればクリアです。

各更新は requestAnimationFrame の1回です。更新の速さは環境により変わるので、ここでは秒ではなく更新回数で数えています。敵がゴールに着くと lives が1減り、倒すと所持金が5増えます。

enemies.filter(enemy => enemy.alive) で終了した敵を取り除きます。同じ敵の到着や報酬は1度だけ数えます。残り0なら失敗、3波を防げばクリアです。最初の60では3基まで置け、報酬がたまれば5か所の残りにも置けます。

Rで start() を呼ぶと、敵・弾・タワーの配列、波、残り3、所持金60、生成までの待ち時間を戻します。

  ctx.fillText("敵の集団 " + wave + " / 3  拠点の残り " + lives + "  所持金 " + money, 80, 45);
  if (state === "playing") ctx.fillText("枠をクリック: 1基20", 80, 410);
  else if (state === "clear") ctx.fillText("守りきった！ R でもう一度", 80, 410);
  else ctx.fillText("突破された！ R でもう一度", 80, 410);
}

function pointFromClick(event) {
  const rect = canvas.getBoundingClientRect();
  return {
    x: (event.clientX - rect.left) * canvas.width / rect.width,
    y: (event.clientY - rect.top) * canvas.height / rect.height
  };
}

canvas.addEventListener("click", (event) => {
  if (state !== "playing") return;
  const point = pointFromClick(event);
  for (const spot of spots) {
    if (point.x >= spot.x - 20 && point.x < spot.x + 20 &&
        point.y >= spot.y - 20 && point.y < spot.y + 20) {
      if (towers.some(tower => tower.x === spot.x && tower.y === spot.y)) return;
      if (money < 20) return;
      money -= 20;
      towers.push(new Tower(spot.x, spot.y));
      return;
    }
  }
});

window.addEventListener("keydown", (event) => {
  if (!event.repeat && event.key.toLowerCase() === "r") start();
});

function gameLoop() {
  update();
  draw();
  requestAnimationFrame(gameLoop);
}

start();
gameLoop();
