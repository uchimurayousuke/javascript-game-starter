基本編の完成版から始めます。ZIPを展開してできたフォルダーでindex.htmlを開きます。ZIPには基本編の3ファイルが入っています。

各段階の変更を上から順に加え、保存したら index.html を開くか再読み込みします。

ステップ 1：1手戻す

このステップの見本を図で見る
ゲーム画面とコードの前後を見る

目標

Uで直前の移動を戻します。

確認欄までは準備中です。作業を順に進め、確認欄で保存して動作を確かめます。

書く場所と置き換えるコード

履歴を覚える

作業用フォルダーの script.js で、次の範囲を探して置き換えます。

置き換える範囲

let board, player, state, level;

置き換えるコード

let board, player, state, level, history;

history は移動前の盤面と人の位置を記録します。

履歴を空にする

作業用フォルダーの script.js で、次の目印を探し、その直後に書きます。

目印

  player = {x: 3, y: 5}; state = "playing";

書き足すコード

  history = [];

面を読み込むたびに履歴を空にします。

戻す操作を案内する

作業用フォルダーの script.js で、次の目印を探し、その直後に書きます。

目印

  ctx.fillText("矢印: 移動 / R: 再開", 440, 100);

書き足すコード

  ctx.fillText("U: 1手戻す", 440, 140);

U キーで1手戻せることを表示します。

U キーで前の状態に戻す

作業用フォルダーの script.js で、次の目印を探し、その直後に書きます。

目印

  if (key === "r") { start(); return; }

書き足すコード

  if (key === "u" && history.length > 0) {
    const saved = history.pop(); board = saved.board.map(row => [...row]); player = {...saved.player}; state = "playing"; return;
  }

履歴があれば pop() で最後の記録を取り出し、盤面と人をコピーして戻します。

箱を押す前の状態を保存する

作業用フォルダーの script.js で、次の目印を探し、その直後に書きます。

目印

    if (next !== "." && next !== "g") return;

書き足すコード

    history.push({board: board.map(row => [...row]), player: {...player}});

有効な箱押しの前に盤面の各行と人の位置をコピーして履歴に入れます。

歩く前の状態も保存する

作業用フォルダーの script.js で、次の範囲を探して置き換えます。

置き換える範囲

    board[ny][nx] = cell === "B" ? "g" : ".";
  }

置き換えるコード

    board[ny][nx] = cell === "B" ? "g" : ".";
  } else history.push({board: board.map(row => [...row]), player: {...player}});

箱を押さない移動でも、移動前の状態を履歴に入れます。

保存後の確かめ方

保存してゲーム画面を更新する（動画）

箱を押した後にUを押すと、人と箱が前の位置へ戻ります。 この段階の見本を開く

小さな練習

目標や評価の値を変えて比べます。 練習後はコードを元に戻してください。

このステップ終了時の見本と自分のコードを比べる

ステップ 2：歩数と評価

このステップの見本を図で見る
ゲーム画面とコードの前後を見る

目標

歩数を数え、30歩以下で評価します。

確認欄までは準備中です。作業を順に進め、確認欄で保存して動作を確かめます。

書く場所と置き換えるコード

歩数を覚える

作業用フォルダーの script.js で、次の範囲を探して置き換えます。

置き換える範囲

let board, player, state, level, history;

置き換えるコード

let board, player, state, level, history, steps;

steps は有効な移動の回数です。

歩数を0に戻す

作業用フォルダーの script.js で、次の目印を探し、その直後に書きます。

目印

  history = [];

書き足すコード

  steps = 0;

面を読み込んだら歩数を0にします。

歩数を表示する

作業用フォルダーの script.js で、次の目印を探し、その直後に書きます。

目印

  ctx.fillText("U: 1手戻す", 440, 140);

書き足すコード

  ctx.fillText("歩数: " + steps, 440, 180);

現在の歩数を画面に表示します。

歩数に応じて評価する

作業用フォルダーの script.js で、次の目印を探し、その直後に書きます。

目印

  if (state === "clear") ctx.fillText("クリア！ 箱を全部置いた", 440, 240);

書き足すコード

  if (state === "clear") ctx.fillText(steps <= 30 ? "評価: よくできた" : "評価: 完了", 440, 280);

クリア時に30歩以下なら「よくできた」、それ以外は「完了」と表示します。

戻すとき歩数も戻す

作業用フォルダーの script.js で、次の範囲を探して置き換えます。

置き換える範囲

    const saved = history.pop(); board = saved.board.map(row => [...row]); player = {...saved.player}; state = "playing"; return;

置き換えるコード

    const saved = history.pop(); board = saved.board.map(row => [...row]); player = {...saved.player}; state = "playing"; steps = saved.steps; return;

履歴の歩数を steps に戻します。

箱を押す前の歩数を保存する

作業用フォルダーの script.js で、次の範囲を探して置き換えます。

置き換える範囲

    history.push({board: board.map(row => [...row]), player: {...player}});

置き換えるコード

    history.push({board: board.map(row => [...row]), player: {...player}, steps});

盤面と人の位置に加えて歩数も履歴に入れます。

歩く前の歩数を保存する

作業用フォルダーの script.js で、次の範囲を探して置き換えます。

置き換える範囲

  } else history.push({board: board.map(row => [...row]), player: {...player}});

置き換えるコード

  } else history.push({board: board.map(row => [...row]), player: {...player}, steps});

箱を押さない移動でも歩数を記録します。

有効な移動を1歩と数える

作業用フォルダーの script.js で、次の目印を探し、その直後に書きます。

目印

  player = {x: nx, y: ny};

書き足すコード

  steps++;

壁や押せない箱を除いた後、人が移動したら steps++ で1増やします。

保存後の確かめ方

移動すると歩数が増え、Uで戻すと歩数も戻ります。 この段階の見本を開く

小さな練習

目標や評価の値を変えて比べます。 練習後はコードを元に戻してください。

このステップ終了時の見本と自分のコードを比べる

ステップ 3：2つのステージ

このステップの見本を図で見る
ゲーム画面とコードの前後を見る

目標

1面の後に2面へ進みます。

確認欄までは準備中です。作業を順に進め、確認欄で保存して動作を確かめます。

書く場所と置き換えるコード

面に応じたクリアを表示する

作業用フォルダーの script.js で、次の範囲を探して置き換えます。

置き換える範囲

  if (state === "clear") ctx.fillText("クリア！ 箱を全部置いた", 440, 240);

置き換えるコード

  if (state === "clear") ctx.fillText(level === 0 ? "完了！ Enterで次の面" : "2面クリア！", 440, 240);

面0のクリア後は Enter で次へ、面1なら2面クリアと表示します。

Enter で次の面を始める

作業用フォルダーの script.js で、次の目印を探し、その直後に書きます。

目印

  if (key === "r") { start(); return; }

書き足すコード

  if (key === "enter" && state === "clear" && level === 0) { level = 1; loadLevel(); return; }

面0をクリアした状態で Enter を押すと、面1を選んで loadLevel() を呼びます。

保存後の確かめ方

1面を解いてEnterを押し、2面を解きます。 この段階の見本を開く

小さな練習

目標や評価の値を変えて比べます。 練習後はコードを元に戻してください。

このステップ終了時の見本と自分のコードを比べる
