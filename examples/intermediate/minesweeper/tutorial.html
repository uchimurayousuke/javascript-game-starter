書き足すコード

function openCell(x, y) {
  const cell = cells[y][x];
  if (cell.open || cell.flag || state !== "playing") return;
  cell.open = true;
  if (cell.bomb) { state = "over"; return; }
  if (cells.flat().every(c => c.bomb || c.open)) { state = "clear"; }
}

開いたマスや旗のあるマス、終了後は処理しません。爆弾なら終了し、爆弾以外がすべて開けばクリアです。flat() は行をまとめ、every() はすべてのマスを調べます。

旗があれば「旗」、開いていれば爆弾や周囲の数を描きます。周囲が0のときは空欄です。

function point(event) {
  const rect = canvas.getBoundingClientRect();
  return {x: Math.floor(((event.clientX - rect.left) * canvas.width / rect.width - 50) / 42), y: Math.floor(((event.clientY - rect.top) * canvas.height / rect.height - 50) / 42)};
}
function gameLoop()

表示上のクリック位置を Canvas 内部の座標に直し、左上50と間隔42から列と行を求めます。Math.floor() は小数点以下を切り捨てます。例えば内部座標が (134, 92) なら、(134 - 50) / 42 = 2、(92 - 50) / 42 = 1 なので列 2・行 1 です。
