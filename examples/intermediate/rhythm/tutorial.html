window.addEventListener("keydown", event => {
  if (event.repeat) return;
  const key = event.key.toLowerCase();
  if (key === "r") { start(); return; }
  if (key === "enter" && state === "ready") { state = "playing"; startTime = performance.now(); message = "タイミングを合わせよう"; return; }

ステップ 3：タイミングで判定する

このステップの見本を図で見る

目標

リズムゲームの仕組みを作ります。

確認欄までは準備中です。作業を順に進め、確認欄で保存して動作を確かめます。

書く場所と置き換えるコード

プレイ中の Space を受け取る

作業用フォルダーの script.js で、次の目印を探し、その直後に書きます。

目印

  if (key === "enter" && state === "ready") { state = "playing"; startTime = performance.now(); message = "タイミングを合わせよう"; return; }

書き足すコード

  if (state !== "playing") return;
  const lane = event.key === " " ? 0 : -1;
  if (lane < 0) return;
  event.preventDefault();

プレイ中でなければ処理せず、Space 以外も除きます。preventDefault() でブラウザーの標準動作を止めます。

時刻が最も近いノーツを探す

作業用フォルダーの script.js で、次の目印を探し、その直後に書きます。

目印

  if (state !== "playing") return;
  const lane = event.key === " " ? 0 : -1;
  if (lane < 0) return;
  event.preventDefault();

書き足すコード

  const elapsed = performance.now() - startTime;
  let nearest = -1, gap = Infinity;
  for (let i = 0; i < beats.length; i++) {
    if (!judged[i] && Math.abs(elapsed - beats[i].time) < gap) { nearest = i; gap = Math.abs(elapsed - beats[i].time); }
  }

未判定のノーツを順に調べ、Math.abs() で入力時刻との差を求めます。最小の差を gap、その番号を nearest に覚えます。

150ミリ秒以内なら成功にする

作業用フォルダーの script.js で、次の目印を探し、その直後に書きます。

目印

  const elapsed = performance.now() - startTime;
  let nearest = -1, gap = Infinity;
  for (let i = 0; i < beats.length; i++) {
    if (!judged[i] && Math.abs(elapsed - beats[i].time) < gap) { nearest = i; gap = Math.abs(elapsed - beats[i].time); }
  }

書き足すコード

  if (nearest >= 0 && gap <= 150) {
    judged[nearest] = true; score++;
    message = "成功！";
  }

候補があり、差が150ミリ秒以下なら判定済みにして得点を1増やします。

function update() {

書き足すコード
