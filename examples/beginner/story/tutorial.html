ステップ 1：森の場面を描く

このステップの見本を図で見る
ゲーム画面とコードの前後を見る

目標

場面と選択肢を少しずつ追加します。

確認欄までは準備中です。作業を順に進め、確認欄で保存して動作を確かめます。

書く場所と置き換えるコード

場面と持ち物を用意する

作業用フォルダーの script.js で、次の目印を探し、その直前に書きます。

目印

function start()

書き足すコード

let scene, items, message;

変数は値に名前を付けて覚えるものです。scene は今の場面、items は持ち物の配列、message は表示する文章です。配列には複数の値を順に入れられます。

入口から始める

作業用フォルダーの script.js で、次の範囲を探して置き換えます。

置き換える範囲

function start() {
}

function update() {
}

置き換えるコード

function start() {
  scene = "start"; items = []; message = "";
}

function update() {

}

= は右の値を左の変数に入れ、; は文の区切りです。場面を入口の "start" にし、[] で持ち物を空に、"" で文章を空にします。

入口の文章を描く

作業用フォルダーの script.js で、次の範囲を探して置き換えます。

置き換える範囲

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
}

置き換えるコード

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "#26334a"; ctx.font = "26px sans-serif";
  if (scene === "start") {
    ctx.fillText("森の入口に立っています。", 70, 90);
  }
}

ctx はひな型が用意した描画の道具です。fillStyle は色、font は文字の大きさと書体です。=== で場面を確かめ、入口なら座標 (70, 90) に文章を描きます。

保存後の確かめ方

保存してゲーム画面を更新する（動画）

森の入口の文章が表示されます。 この段階の見本を開く

小さな練習

場面の文章を変えて表示を確かめます。 練習後はコードを元に戻してください。

ステップ 3：選択して場面を変える

このステップの見本を図で見る

目標

場面と選択肢を少しずつ追加します。

確認欄までは準備中です。作業を順に進め、確認欄で保存して動作を確かめます。

書く場所と置き換えるコード

川と広場の文章を描く

作業用フォルダーの script.js で、次の目印を探し、その直後に書きます。

目印

    ctx.fillText("1: 広場へ進む　2: 川へ進む", 70, 160);

書き足すコード

  } else if (scene === "river") {
    ctx.fillText("川の水が急に増えたので、家へ戻りました。", 70, 90);
    ctx.fillText("おしまい", 70, 160);
  } else if (scene === "clearing") {
    ctx.fillText("広場に着きました。", 70, 90);
    ctx.fillText("1: 家へ帰る　2: 森を見渡す", 70, 160);

"river" なら川の結末、"clearing" なら広場の文章と選択肢を描きます。広場の選択による結末は次のステップで作ります。

キー入力を受け取る準備をする

作業用フォルダーの script.js で、次の範囲を探して置き換えます。

置き換える範囲





function gameLoop()

置き換えるコード



window.addEventListener("keydown", event => {
});

function gameLoop()

keydown はキーを押したときに起きます。

使わないキーを除く

作業用フォルダーの script.js で、次の目印を探し、その直後に書きます。

目印

window.addEventListener("keydown", event => {

書き足すコード

  if (event.repeat) return;
  const key = event.key.toLowerCase();
  if (!["1", "2", "3"].includes(key) || scene === "end" || scene === "river") return;
  if (key === "3") return;

event.repeat が真なら押しっぱなしによる入力を無視します。toLowerCase() は英字を小文字にします。includes() で数字1〜3かを確かめ、結末や川では処理を終えます。この段階では3も使いません。

入口から行き先を選ぶ

作業用フォルダーの script.js で、次の目印を探し、その直後に書きます。

目印

  if (event.repeat) return;
  const key = event.key.toLowerCase();
  if (!["1", "2", "3"].includes(key) || scene === "end" || scene === "river") return;
  if (key === "3") return;

書き足すコード

  if (scene === "start") scene = key === "1" ? "clearing" : key === "2" ? "river" : scene;

入口で1を押すと "clearing"、2を押すと "river" になります。条件 ? A : B は条件が正しいときA、それ以外はBを選びます。

保存後の確かめ方

1で広場、再読み込み後に2で川の場面を表示します。 この段階の見本を開く

小さな練習

場面の文章を変えて表示を確かめます。 練習後はコードを元に戻してください。

ステップ 4：2つの結末を作る

このステップの見本を図で見る

目標

場面と選択肢を少しずつ追加します。

確認欄までは準備中です。作業を順に進め、確認欄で保存して動作を確かめます。

書く場所と置き換えるコード

結末の文章を描く

作業用フォルダーの script.js で、次の目印を探し、その直後に書きます。

目印

    ctx.fillText("1: 家へ帰る　2: 森を見渡す", 70, 160);

書き足すコード

  } else if (scene === "end") {
    ctx.fillText(message, 70, 90);
    ctx.fillText("おしまい", 70, 160);

message には選択に応じた結末を入れます。"end" になったら、その文章と「おしまい」を描きます。

広場から2つの結末へ

作業用フォルダーの script.js で、次の目印を探し、その直後に書きます。

目印

  if (scene === "start") scene = key === "1" ? "clearing" : key === "2" ? "river" : scene;

書き足すコード

  else if (scene === "clearing" && key === "1") { scene = "end"; message = "森の景色を楽しみ、家へ帰りました。"; }
  else if (scene === "clearing" && key === "2") { scene = "end"; message = "見晴らしのよい丘を見つけました。"; }

&& は両方の条件が成り立つときです。広場で1なら帰る結末、2なら丘を見つける結末を入れ、どちらも scene を "end" にします。

保存後の確かめ方

広場で1か2を選ぶと、それぞれ違う結末になります。 この段階の見本を開く

小さな練習
