コードの比較の読み方

比較欄では消す行、追加する行、そのままの行を色とラベルで示します。長い比較では変更のない途中の行を省略することがあります。比較欄は読むためのもので、選択してコピーする欄ではありません。

− 消す＋ 追加そのまま

「置き換える」場合は、赤い行だけを消すのではなく、指定された変更前の範囲すべてをコピー用のコード全体に置き換えます。そのままの行もコピー用のコードに含まれます。古い関数を残して同じ名前の関数を追加しないでください。「追加する」場合は、指定された場所にコピー用のコードを加えます。

コピーするのは「コピー用」と書かれたコード欄です。比較欄のラベルや記号はコードに入りません。全文の見本は手元のコードを見比べるための参考です。

draw() から gameLoop() の直前

次は説明用の抜粋です。編集には、この後の「比較とコピー用コード」を開いて使います。

得点を表示する

現在の得点を描きます。

ctx.fillStyle = "#26334a";
ctx.font = "24px sans-serif";
ctx.fillText("得点: " + score, 20, 35);

+ で文字と score をつなぎ、座標 (20, 35) に描きます。

クリック位置を Canvas の座標に直す

表示上の位置と大きさを使って変換します。

canvas.addEventListener("click", (event) => {
  const rect = canvas.getBoundingClientRect();
  const x = (event.clientX - rect.left) * canvas.width / rect.width;
  const y = (event.clientY - rect.top) * canvas.height / rect.height;

addEventListener() はクリック時の処理を登録します。rect には画面上の Canvas の位置と大きさが入ります。clientX - rect.left は表示された Canvas の左端からクリック位置までの距離です。内部の幅を表示幅で割った比を掛けると、Canvas 内部の横座標になります。縦も上端と高さで同じように変換します。

中心からの距離で当たりを調べる

クリック位置が円の中か円周上なら命中です。

if (Math.hypot(x - targetX, y - targetY) <= radius) {
  score++;

x - targetX と y - targetY は中心からクリック位置までの横と縦の差です。Math.hypot() はその2つから距離を求めます。距離が半径以下なら score++ で1点増やします。中心 (400, 225) から (435, 225) は距離35なので円周上も当たり、(436, 225) は距離36で外れです。

的を新しい位置へ移す

命中後、的が画面内に収まる位置を選びます。

targetX = radius + Math.random() * (canvas.width - radius * 2);
targetY = radius + Math.random() * (canvas.height - radius * 2);

Math.random() は0以上1未満の数を作ります。横は画面幅から半径2つ分を引いた範囲に半径を足し、中心が端に近づきすぎないようにします。縦も同じ考え方です。

残り時間を表示する

締切と現在時刻の差から残り秒数を求めます。

const seconds = Math.max(0, Math.ceil((endTime - performance.now()) / 1000));
ctx.fillStyle = "#26334a";
ctx.font = "24px sans-serif";
ctx.fillText("得点: " + score + "  残り: " + seconds + "秒", 20, 35);
if (seconds === 0) ctx.fillText("終了！ R キーでもう一度", 220, 225);

残りミリ秒を1000で割り、Math.ceil() で端数を切り上げます。Math.max(0, ...) で0より小さくせず、0なら終了の文字を描きます。

締切後のクリックを止める

クリックした時刻も確認します。

if (performance.now() >= endTime) return;

現在時刻が締切以上なら return で処理を終えるので、当たっても得点は増えません。

R キーでやり直す

最初の位置、得点、締切に戻します。

window.addEventListener("keydown", (event) => {
  if (event.key.toLowerCase() === "r") start();
});

toLowerCase() で入力を小文字にして R キーを判定し、start() を呼びます。すでに動いている gameLoop() を再び呼ぶと更新が二重になるため、ここでは呼びません。

"use strict";
const canvas = document.querySelector("#game-canvas");
const ctx = canvas.getContext("2d");

let targetX, targetY, score, endTime;
const radius = 35;

function start() {
  targetX = 400;
  targetY = 225;
  score = 0;
  endTime = performance.now() + 20000;
}

function update() {
}

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "#e34b5f";
  ctx.beginPath();
  ctx.arc(targetX, targetY, radius, 0, Math.PI * 2);
  ctx.fill();
  const seconds = Math.max(0, Math.ceil((endTime - performance.now()) / 1000));
  ctx.fillStyle = "#26334a";
  ctx.font = "24px sans-serif";
  ctx.fillText("得点: " + score + "  残り: " + seconds + "秒", 20, 35);
  if (seconds === 0) ctx.fillText("終了！ R キーでもう一度", 220, 225);
}

canvas.addEventListener("click", (event) => {
  if (performance.now() >= endTime) return;
  const rect = canvas.getBoundingClientRect();
  const x = (event.clientX - rect.left) * canvas.width / rect.width;
  const y = (event.clientY - rect.top) * canvas.height / rect.height;
  if (Math.hypot(x - targetX, y - targetY) <= radius) {
    score++;
    targetX = radius + Math.random() * (canvas.width - radius * 2);
    targetY = radius + Math.random() * (canvas.height - radius * 2);
  }
});
window.addEventListener("keydown", (event) => {
  if (event.key.toLowerCase() === "r") start();
});
function gameLoop() {
  update();
  draw();
  requestAnimationFrame(gameLoop);
}

start();
gameLoop();
