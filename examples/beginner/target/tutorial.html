クリックで的あて

初心者向け

変数、関数、if 文と Canvas の基本の描画を知っている人向けです。 円の描画、クリック位置、距離と得点を学びます。

20秒の間に赤い的をクリックします。終了後は R キーで再挑戦できます。

完成版で遊ぶ

コードの比較の読み方

比較欄では消す行、追加する行、そのままの行を色とラベルで示します。長い比較では変更のない途中の行を省略することがあります。比較欄は読むためのもので、選択してコピーする欄ではありません。

− 消す＋ 追加そのまま

「置き換える」場合は、赤い行だけを消すのではなく、指定された変更前の範囲すべてをコピー用のコード全体に置き換えます。そのままの行もコピー用のコードに含まれます。古い関数を残して同じ名前の関数を追加しないでください。「追加する」場合は、指定された場所にコピー用のコードを加えます。

コピーするのは「コピー用」と書かれたコード欄です。比較欄のラベルや記号はコードに入りません。全文の見本は手元のコードを見比べるための参考です。

template/ の index.html、style.css、script.js を新しい作業用フォルダーにコピーします。3つのファイルを同じ場所に置いてください。元のひな型は残しておきます。

各ステップでは作業用フォルダーの script.js を開き、示した部分を順番に置き換えます。index.html と style.css は変更しません。保存したら作業用の index.html をブラウザで開き、すでに開いている場合は再読み込みしてください。見本は別のページで開けます。

start() は最初の設定、update() は動きや判定、draw() は描画を担当します。最後の gameLoop() は更新と描画を繰り返します。

"use strict";
const canvas = document.querySelector("#game-canvas");
const ctx = canvas.getContext("2d");

let targetX, targetY, score;
const radius = 35;

function start() {
  targetX = 400;
  targetY = 225;
  score = 0;
}

function update() {

}

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "#e34b5f";
  ctx.beginPath();
  ctx.arc(targetX, targetY, radius, 0, Math.PI * 2);
  ctx.fill();
  ctx.fillStyle = "#26334a";
  ctx.font = "24px sans-serif";
  ctx.fillText("得点: " + score, 20, 35);
}

canvas.addEventListener("click", (event) => {
  const rect = canvas.getBoundingClientRect();
  const x = (event.clientX - rect.left) * canvas.width / rect.width;
  const y = (event.clientY - rect.top) * canvas.height / rect.height;
  if (Math.hypot(x - targetX, y - targetY) <= radius) {
    score++;
    targetX = radius + Math.random() * (canvas.width - radius * 2);
    targetY = radius + Math.random() * (canvas.height - radius * 2);
  }
});
function gameLoop() {
  update();
  draw();
  requestAnimationFrame(gameLoop);
}
start();
gameLoop();
