# コインキャッチを作ろう

落ちてくるコインを受け皿で集める、キーボード操作のミニゲームを作ります。Canvas に描くところから始め、位置の更新、入力、当たり判定を順に追加します。完成版は「3回落とす前に5枚集めるとクリア」です。

## 始め方

1. リポジトリをパソコンにダウンロードまたはクローンします。
2. `01-draw/index.html` を Chrome や Edge などのブラウザで開きます。ファイルのダブルクリックで動きます。
3. 同じフォルダーの `script.js` をエディターで開き、下の説明とコードを見比べます。
4. 数値や色を1か所変えて保存し、ブラウザを再読み込みします。
5. ページ下の「次へ」で次の段階を開き、前の `script.js` と見比べます。

各フォルダーはその段階の完成コードです。前のステップを変更しても、次のステップには影響しません。自分で最初から組み立てたい場合は、ルートにある3ファイルを別の練習用フォルダーにコピーし、各段階を参考にして書き足してください。

## ファイルと関数の役割

| 場所 | 役割 |
| --- | --- |
| 各 `index.html` | 説明文と、800 × 450 の Canvas を配置する |
| 各 `style.css` | ページの色・余白と Canvas の表示サイズを決める |
| 各 `script.js` | ゲームのデータ、入力、動き、描画を書く |
| `start()` | ゲームを始めるときの値を設定する |
| `update()` | 毎フレーム、位置や得点などのデータを変える |
| `draw()` | 毎フレーム、現在のデータを画面に描く |
| `gameLoop()` | `update()` → `draw()` を繰り返す。全ステップで共通 |

HTML の `width="800" height="450"` は Canvas 内部の座標の広さです。CSS はその画面をブラウザの幅に合わせて縮めて表示します。内部の座標は変わらないので、JavaScript はいつも 800 × 450 の画面として計算できます。

## STEP 01 — 図形を描く

編集するファイルは [01-draw/script.js](01-draw/script.js) です。まずは `draw()` を読みます。

`ctx.fillRect()` で青い受け皿、`ctx.arc()` と `ctx.fill()` で丸いコイン、`ctx.fillText()` で文字を描きます。Canvas の左上が `(0, 0)` で、`x` は右へ、`y` は下へ増えます。受け皿の座標は左上、コインの座標は中心を表しています。

`ctx.clearRect()` は前のフレームの絵を消します。今は同じ位置に描き直しているので、動かない画面に見えます。`start()` と `update()` はまだ空です。

**試す:** `draw()` の `#2563eb` を別の色に変えましょう。次に `coinRadius` を `24` にして、丸がどう変わるか確かめましょう。

## STEP 02 — データを更新して動かす

編集するファイルは [02-update/script.js](02-update/script.js) です。`coinSpeed` を用意し、`start()`・`update()` と新しい `resetCoin()` を書きます。

`start()` でコインを中央上部に置きます。`update()` の `coinY += coinSpeed` で、1フレームごとに縦位置を3ピクセル増やします。`draw()` は STEP 01 と同じですが、変わった座標で描くので落ちて見えます。

`coinY - coinRadius` はコインの上端です。上端まで画面の下に出たら `resetCoin()` を呼び、ランダムな横位置で上へ戻します。`Math.random()` は 0 以上 1 未満の数を返します。

**試す:** `coinSpeed` を `1` や `5` に変えましょう。さらに `resetCoin()` の横位置を `canvas.width / 2` にすると、毎回同じ場所から落ちます。

## STEP 03 — キー入力を動きにつなげる

編集するファイルは [03-input/script.js](03-input/script.js) です。入力用の変数と関数、イベント登録を追加し、`start()` と `update()` も編集します。

`handleKeyDown()` はキーを押したときに `leftPressed` または `rightPressed` を `true` にします。`handleKeyUp()` は離したときに `false` に戻します。`update()` がその値を毎フレーム調べるので、押している間だけ受け皿が動きます。`event.preventDefault()` は矢印キーによるページのスクロールを防ぎます。

`Math.min()` と `Math.max()` で `playerX` を `0` から `canvas.width - playerWidth` の間に収め、画面の外へ出るのを防ぎます。別のタブへ移ったときは `clearKeys()` で入力を解除します。

**試す:** `playerSpeed` を変えてみましょう。左右の端まで動かし、キーを離すと止まることも確認しましょう。この段階ではコインは受け皿を通り抜けます。

## STEP 04 — 当たり判定で得点を増やす

編集するファイルは [04-collision/script.js](04-collision/script.js) です。`score` を用意し、`start()` で `0` に戻します。`coinTouchesPlayer()` を追加し、`update()` と `draw()` も編集します。

ここではコインを囲む四角と、受け皿の四角の重なりで判定します。`coinTouchesPlayer()` の4つの条件は、コインの下端・上端・右端・左端をそれぞれ受け皿の端と比べています。`&&` は「すべての条件を満たす」という意味です。

重なったら `update()` で `score` を1増やして、すぐに `resetCoin()` で次のコインへ進めます。1枚で何度も加点されるのを防ぐためです。`draw()` は `score` を文字として表示します。まだ残り回数はなく、落としても続きます。

**試す:** `playerWidth` を `60` に変えて難しくしましょう。受け皿の中央と端の両方でキャッチし、得点が1ずつ増えるか確かめましょう。

## STEP 05 — 終了と再挑戦を作る

編集するファイルは [05-game/script.js](05-game/script.js) です。`targetScore`・`startingLives`・`lives`・`gameState` を追加し、`start()`・`update()`・`draw()`・`handleKeyDown()` を編集します。

`gameState` には `"playing"`（プレイ中）、`"clear"`（クリア）、`"gameover"`（失敗）のどれかを入れます。5枚集めたらクリア、3回落としたらゲームオーバーです。終了後の `update()` は `return` で抜け、位置や得点を止めます。`draw()` は結果と再挑戦の案内を重ねて描きます。

終了後に Space キーを押すと `start()` を呼び、位置・得点・残り回数・入力・状態を最初に戻します。ゲームループは最初の1本を使い続けます。ここで `gameLoop()` を再び呼ぶと、ループが増えて動きが速くなるので注意しましょう。

**試す:** `targetScore` や `startingLives` を変えましょう。クリアとゲームオーバーの両方を試し、Space キーで最初の状態に戻るか確認しましょう。数値を変更したら、HTML のルール説明も合わせて直します。

## 自分のゲームへ広げるなら

受け皿の色や幅、落下速度、必要な枚数を変えるだけでも、遊びやすさは変わります。慣れてきたら、コインを捕まえるたびに速くする、新しい図形を描く、キーを追加するなど、1つずつ試してみてください。

各ステップは独立した3ファイルで動き、外部ライブラリや画像、開発用サーバーは使いません。操作にはパソコンのキーボードを使います。
