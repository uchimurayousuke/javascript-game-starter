自分で考える課題

まず答えを予想し、必要なときだけヒントを開きます。自分のコピーで試すと変更を作品に残せます。

1. 体力を予想する

hpが100で、30減らしてから20回復するといくつ？

ヒント

引き算を先にします。

答えと理由

90です。100−30＋20で90になります。

2. 座標を予想する

位置(100,80)からxを20増やし、yを10減らすとどこ？

ヒント

xとyを別々に計算します。

答えと理由

(120,70)です。右へ20、上へ10動きます。

3. 条件の穴埋め

scoreが5以上ならclearにするには、空欄に何を入れる？

if (score ___ 5) { gameState = "clear"; }
ヒント

5も含む「以上」を表します。

答えと理由

>=です。5とそれより大きい値で真になります。

4. 得点処理の順番

コインに触れたら「コインを元に戻す」「得点に1を足す」。得点が増え続けないために何が必要？

ヒント

次の更新で同じ接触条件が真のままかを考えます。

答えと理由

加点後、コインを接触していない位置に戻します。次の更新で同じ接触を繰り返して数えないためです。

こわれた見本で確かめる

5. 配列の番号

["赤", "青", "緑"]の「青」を取り出す番号は？

ヒント

先頭の番号は0です。

答えと理由

1です。0、1、2の順に並びます。

6. 状態を選ぶ

menuではEnter、playingでは矢印を使いたいとき、入力する前に何を確認する？

ヒント

今どの画面かを表す値に注目します。

答えと理由

gameStateを調べます。今の画面に合う操作だけを受け付けます。

7. ヒントだけで改造

自分のコインキャッチで目標枚数を変え、表示とクリア条件を確かめましょう。気に入った数は作品に残して構いません。

ヒント

targetScoreを探し、数字を1か所変えて保存します。クリアと表示の両方を試します。

答えと理由

例えばtargetScoreを3にすると、3枚でクリアし、目標表示も3になります。同じ値を両方で使うためです。

8. 自由制作

プレイヤー、集めるもの、終わり方を1つずつ決め、動く最小版を作ります。背景や画像など、必要な機能を後から1つ足しましょう。

ヒント

企画シートに書いてから、近い作例を選びます。

例と理由

落ちる星を3個集めるゲームなら、コインキャッチの見た目と目標を変えて始められます。まず遊べる形にしてから広げられます。
