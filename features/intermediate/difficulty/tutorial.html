難易度設定を作る

コードの比較の読み方

比較欄では消す行、追加する行、そのままの行を色とラベルで示します。変更のない途中の行を省略することがあります。比較欄は読むためのもので、コピーする欄ではありません。

− 消す＋ 追加そのまま

置き換えるときは、赤い行だけを消すのではなく、指定された変更前の範囲すべてをコピー用のコードに置き換えます。そのままの行もコピー用のコードに含まれます。古い関数を残して同じ名前の関数を追加しないでください。

コピーするのは「コピー用」と書かれたコード欄です。比較の記号はコードに入りません。

"use strict";

const canvas = document.querySelector("#game-canvas");
const ctx = canvas.getContext("2d");

let selected, state, x;

function start() {
  selected = 0; state = "menu"; x = 100;
}

function update() {
  if (state === "playing") { x += selected === 0 ? 2 : 4; if (x > 700) x = 100; }
}

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "#26334a"; ctx.font = "28px sans-serif";
  if (state === "menu") ctx.fillText("難易度: " + (selected === 0 ? "普通" : "速い"), 200, 120);
  else { ctx.fillText("R: 設定へ", 200, 120); ctx.fillRect(x, 200, 40, 40); }
  if (state === "menu") ctx.fillText("←→で選ぶ / Enterで開始", 160, 200);
}

window.addEventListener("keydown", event => {
  if (event.repeat) return;
  if (event.key.toLowerCase() === "r") { start(); return; }
  if (state !== "menu") return;
  if (event.key === "ArrowLeft" || event.key === "ArrowRight") { event.preventDefault(); selected = 1 - selected; }
  else if (event.key === "Enter") state = "playing";
});

function gameLoop() {
  update();
  draw();
  requestAnimationFrame(gameLoop);
}

自分のゲームに組み込むには

selectedと設定画面、選択と決定の処理を移します。

自分のstartGameにselectedを渡し、updateGameの速度や時間を設定に応じて決めます。

この欄のstartGame・updateGame・drawGameは、自分のゲーム側の開始・更新・描画の関数名の例です。自分の関数名に合わせて読み替えます。gameLoopは増やさず、既存のstart・update・drawから必要な処理を呼び、再挑戦では持ち込んだ状態や入力も初期化します。
