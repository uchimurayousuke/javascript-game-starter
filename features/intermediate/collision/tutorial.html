円と四角の当たり判定を作る

コードの比較の読み方

比較欄では消す行、追加する行、そのままの行を色とラベルで示します。変更のない途中の行を省略することがあります。比較欄は読むためのもので、コピーする欄ではありません。

− 消す＋ 追加そのまま

置き換えるときは、赤い行だけを消すのではなく、指定された変更前の範囲すべてをコピー用のコードに置き換えます。そのままの行もコピー用のコードに含まれます。古い関数を残して同じ名前の関数を追加しないでください。

コピーするのは「コピー用」と書かれたコード欄です。比較の記号はコードに入りません。

  x = 180; y = 225;

}

function draw() {

  if (event.key === "ArrowLeft") { event.preventDefault(); x = Math.max(radius, x - 10); }
  else if (event.key === "ArrowRight") { event.preventDefault(); x = Math.min(800 - radius, x + 10); }
  else if (event.key === "ArrowUp") { event.preventDefault(); y = Math.max(radius, y - 10); }
  else if (event.key === "ArrowDown") { event.preventDefault(); y = Math.min(450 - radius, y + 10); }
});

function gameLoop() {
  update();
  draw();
  requestAnimationFrame(gameLoop);
}

start();
gameLoop();
