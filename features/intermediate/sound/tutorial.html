効果音と音量を作る

コードの比較の読み方

比較欄では消す行、追加する行、そのままの行を色とラベルで示します。変更のない途中の行を省略することがあります。比較欄は読むためのもので、コピーする欄ではありません。

− 消す＋ 追加そのまま

置き換えるときは、赤い行だけを消すのではなく、指定された変更前の範囲すべてをコピー用のコードに置き換えます。そのままの行もコピー用のコードに含まれます。古い関数を残して同じ名前の関数を追加しないでください。

コピーするのは「コピー用」と書かれたコード欄です。比較の記号はコードに入りません。

ステップ 2：音量とミュートを選ぶ

目標

音量とミュートを選ぶ。

小さな作業

上から順に作業します。目印を探し、その下のコードを書きます。

音量とミュートを表示する

draw() の操作案内の下で、次の目印のすぐ下に追加します。

目印

  ctx.fillText("Space: 音を試す / R: 最初から", 160, 360);

追加するコード

  ctx.fillText("音量 " + volume + " / " + (muted ? "ミュート" : "音あり"), 160, 210);

+ で文字と値をつなぎます。条件 ? A : B は条件に応じて A または B を選び、ミュート中かを表示します。

音の設定操作を案内する

音量表示の下で、次の目印のすぐ下に追加します。

目印

  ctx.fillText("音量 " + volume + " / " + (muted ? "ミュート" : "音あり"), 160, 210);

追加するコード

  ctx.fillText("V: 音量　M: ミュート", 160, 270);

V で音量、M でミュートを切り替える案内を表示します。

Vで音量を切り替える

キー入力処理の Space の判定の下で、次の目印のすぐ下に追加します。

目印

  if (event.key === " ") { event.preventDefault(); message = "音を鳴らす操作を受け付けた"; }

追加するコード

  else if (key === "v") volume = volume === 0 ? 0.25 : volume === 0.25 ? 0.5 : 0;

音量を 0 → 0.25 → 0.5 → 0 の順に切り替えます。

Mでミュートを切り替える

V の判定の下で、次の目印のすぐ下に追加します。

目印

  else if (key === "v") volume = volume === 0 ? 0.25 : volume === 0.25 ? 0.5 : 0;

追加するコード

  else if (key === "m") muted = !muted;

! は真偽を反転します。M を押すたびミュートの有無が切り替わります。

保存して再読み込みし、V で音量が 0.25、0.5、0 と切り替わり、M でミュートの表示が切り替わることを確かめます。音は次に作ります。

ステップ 3：利用できるときに音を鳴らす

目標

利用できるときに音を鳴らす。

小さな作業

上から順に作業します。目印を探し、その下のコードを書きます。

音を扱う準備を覚える

変数の宣言の下で、次の目印のすぐ下に追加します。

目印

let volume, muted, message;

追加するコード

let audioContext = null;

audioContext は音を扱うための機能を後で覚えます。null はまだ値がないことです。

音を鳴らす関数の枠を作る

audioContext の宣言の下で、次の目印のすぐ下に追加します。

目印

let audioContext = null;

追加するコード

async function playSound() {
  if (muted || volume === 0) { message = "ミュート中"; return; }
  try {
  } catch (error) { message = "音を再生できません"; }
}

async は途中で非同期の処理を待てる関数です。|| はどちらか一方が成り立つという意味で、ミュート中か音量 0 なら終了します。失敗は catch で案内します。まだ呼び出さず、中身を続けて作ります。

playSound() の try の中で、次の目印のすぐ下に追加します。

目印

    const Audio = window.AudioContext || window.webkitAudioContext;
    if (!Audio) { message = "この環境では音を使えません"; return; }

利用できる音声機能を選び、どちらもなければ案内して終了します。

音声機能を作り再開する

音声機能がない場合の判定の下で、次の目印のすぐ下に追加します。

目印

    if (!Audio) { message = "この環境では音を使えません"; return; }

追加するコード

    if (!audioContext) audioContext = new Audio();
    if (audioContext.state === "suspended") await audioContext.resume();
    if (audioContext.state !== "running") { message = "音を再生できません"; return; }

初めてなら音声機能を作り、停止中なら await で再開を待ちます。動作状態が running にならなければ案内して終了します。

音源と音量を作る

動作状態の判定の下で、次の目印のすぐ下に追加します。

目印

    if (audioContext.state !== "running") { message = "音を再生できません"; return; }

追加するコード

    const oscillator = audioContext.createOscillator(), gain = audioContext.createGain();
    oscillator.frequency.value = 440; gain.gain.value = volume;

oscillator は音源、gain は音量を調整するものです。音の高さを 440 Hz、音量を volume にします。

音をつなぎ短く鳴らす

音の高さと音量の設定の下で、次の目印のすぐ下に追加します。

目印

    oscillator.frequency.value = 440; gain.gain.value = volume;

追加するコード

    oscillator.connect(gain); gain.connect(audioContext.destination);
    oscillator.start(); oscillator.stop(audioContext.currentTime + 0.08);
    message = "音を再生しました";

音源から音量調整を通して出力につなぎ、開始して 0.08 秒後に止めます。

Spaceで音を鳴らす

キー入力処理の Space の判定で、次の範囲を置き換えます。

置き換える範囲

  if (event.key === " ") { event.preventDefault(); message = "音を鳴らす操作を受け付けた"; }

置き換えるコード

  if (event.key === " ") { event.preventDefault(); playSound(); }

Space で playSound() を呼びます。音が利用できない、または再開に失敗したときは案内が表示されます。

"use strict";

const canvas = document.querySelector("#game-canvas");
const ctx = canvas.getContext("2d");

let volume, muted, message;
let audioContext = null;
async function playSound() {
  if (muted || volume === 0) { message = "ミュート中"; return; }
  try {
    const Audio = window.AudioContext || window.webkitAudioContext;
    if (!Audio) { message = "この環境では音を使えません"; return; }
    if (!audioContext) audioContext = new Audio();
    if (audioContext.state === "suspended") await audioContext.resume();
    if (audioContext.state !== "running") { message = "音を再生できません"; return; }
    const oscillator = audioContext.createOscillator(), gain = audioContext.createGain();
    oscillator.frequency.value = 440; gain.gain.value = volume;
    oscillator.connect(gain); gain.connect(audioContext.destination);
    oscillator.start(); oscillator.stop(audioContext.currentTime + 0.08);
    message = "音を再生しました";
  } catch (error) { message = "音を再生できません"; }
}

function start() {
  volume = 0.25; muted = false; message = "Spaceで音を試す";
}

function update() {

}

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "#26334a"; ctx.font = "28px sans-serif";
  ctx.fillText(message, 160, 140);
  ctx.fillText("Space: 音を試す / R: 最初から", 160, 360);
  ctx.fillText("音量 " + volume + " / " + (muted ? "ミュート" : "音あり"), 160, 210);
  ctx.fillText("V: 音量　M: ミュート", 160, 270);
}

window.addEventListener("keydown", event => {
  if (event.repeat) return;
  const key = event.key.toLowerCase();
  if (key === "r") { start(); return; }
  if (event.key === " ") { event.preventDefault(); playSound(); }
  else if (key === "v") volume = volume === 0 ? 0.25 : volume === 0.25 ? 0.5 : 0;
  else if (key === "m") muted = !muted;
});

function gameLoop() {
  update();
  draw();
  requestAnimationFrame(gameLoop);
}
