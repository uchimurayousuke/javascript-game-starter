ステップ 1：開始から実時間10秒を数える

目標

開始から実時間10秒を数える。

予想してみる

2.5秒後の残りは？

答えを確認する

10 - 2.5で7.5秒です。画面は切り上げて8秒と表示します。

次は説明用の抜粋です。編集には、この後の「比較とコピー用コード」を開いて使います。

開始時刻を記録する

ゲームを始めた時刻と残り秒数を用意します。

let startedAt, remaining;

function start() {
  startedAt = performance.now(); remaining = 10;
}

startedAt は開始時刻、remaining は残り秒数です。performance.now() は時刻をミリ秒で返します。

残り時間を更新する

現在時刻と開始時刻の差を使います。

remaining = Math.max(0, 10 - (performance.now() - startedAt) / 1000);

差を1000で割って秒に直し、10秒から引きます。Math.max(0, ...) は0より小さい値を0にします。

秒数を画面に描く

端数を切り上げて表示します。

ctx.fillText("残り: " + Math.ceil(remaining) + "秒", 230, 160);

Math.ceil() は表示用に切り上げます。たとえば残り7.5秒なら8秒と表示しますが、remaining 自体は7.5のままです。

ステップ 2：残り0秒で時間切れにする

目標

残り0秒で時間切れにする。

予想してみる

10秒ちょうどの残りは？

答えを確認する

0秒です。

次は説明用の抜粋です。編集には、この後の「比較とコピー用コード」を開いて使います。

状態を用意する

始めるときはプレイ中にします。

startedAt = performance.now(); remaining = 10; state = "playing";

state に "playing" を入れ、開始時刻と残り10秒を初期化します。

0になったら時間切れにする

計算した残り秒数で終了を判定します。

remaining = Math.max(0, 10 - (performance.now() - startedAt) / 1000);
if (remaining === 0) state = "over";

残りが0なら "over" にします。表示用の切り上げではなく、計算した remaining を使います。別タブに移った時間も含め、戻った次の更新で差を計算します。

終了を画面に出す

時間切れの状態だけに案内を描きます。

if (state === "over") ctx.fillText("時間切れ", 230, 220);

state が "over" と同じなら文字を表示します。

ステップ 3：Rで10秒からやり直す

目標

Rで10秒からやり直す。

予想してみる

再開時の開始時刻は？

答えを確認する

Rを押したときの現在時刻です。

次は説明用の抜粋です。編集には、この後の「比較とコピー用コード」を開いて使います。

R キーで再開する

対象外のキー入力を除いてから判定します。

if (event.ctrlKey || event.altKey || event.metaKey || event.isComposing) return;
if (event.repeat) return;
if (event.key.toLowerCase() === "r") start();

組み合わせキーや文字の変換中、押しっぱなしは受け取りません。R なら start() が開始時刻を記録し直し、残り10秒とプレイ中に戻します。

時間の更新と表示を続ける

再挑戦後も同じ計算を使います。

remaining = Math.max(0, 10 - (performance.now() - startedAt) / 1000);

update() は開始時刻を変えず、現在との差を使います。ゲームループを増やす必要はありません。OS のスリープ中に時計が進むかは環境によって異なります。

"use strict";

const canvas = document.querySelector("#game-canvas");
const ctx = canvas.getContext("2d");

let startedAt, remaining; let state;

function start() {
  startedAt = performance.now(); remaining = 10; state = "playing";
}

function update() {
  remaining = Math.max(0, 10 - (performance.now() - startedAt) / 1000);
  if (remaining === 0) state = "over";
}

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "#26334a";
  ctx.font = "28px sans-serif";
  ctx.fillText("残り: " + Math.ceil(remaining) + "秒", 230, 160);
  if (state === "over") ctx.fillText("時間切れ", 230, 220);
  ctx.fillText("R: 最初から", 230, 300);
}

window.addEventListener("keydown", event => {
  if (event.ctrlKey || event.altKey || event.metaKey || event.isComposing) return;
  if (event.repeat) return;
  if (event.key.toLowerCase() === "r") start();
});

function gameLoop() {
  update();
  draw();
  requestAnimationFrame(gameLoop);
}

このステップ終了時の見本と自分のコードを比べる

自分のゲームに組み込むには

startedAt を開始と再挑戦のときだけ記録し、update() では現在時刻との差から remaining を求めます。毎回開始時刻を記録し直すと減らないため、初期化と更新を分けます。

見本の状態、入力、更新、描画を自分のゲームの名前に合わせて移します。すでにある start()、update()、draw() に必要な部分を加え、ゲームループは増やしません。やり直すときは追加した状態も初期化してください。
