+ で文字と数をつなぎ、体力と回復薬の数を別々に表示します。体力の上限は10です。

ステップ 2：1で1個使い体力を3回復

目標

1で1個使い体力を3回復。

予想してみる

体力8で使うと？

答えを確認する

3回復しますが上限10になるので10です。

読むための抜粋です。編集には下のコピー用コードを使います。

使う条件と回復量を決める
if (event.key === "1" && potions > 0 && hp < 10) { hp = Math.min(10, hp + 3); potions -= 1; }

1キーを押し、potions > 0 で薬があり、hp < 10 で体力が満タンでないときだけ使います。&& は条件がすべて必要です。Math.min(10, hp + 3) で3回復しても10を超えず、potions -= 1 で薬を1個減らします。体力8なら回復後は10です。

繰り返し入力や変換中を除く
if (event.ctrlKey || event.altKey || event.metaKey || event.isComposing) return;
  if (event.repeat) return;

Ctrl・Alt・Metaとの組み合わせや変換中、押しっぱなしの繰り返し入力なら return し、薬を続けて使わないようにします。

}

}

ステップ 3：Gで拾い最大5個、Rで元に戻す

目標

Gで拾い最大5個、Rで元に戻す。

予想してみる

薬0個で1を押すと？

答えを確認する

体力も個数も変わりません。

読むための抜粋です。編集には下のコピー用コードを使います。

拾う数を5個までにする
if (event.key.toLowerCase() === "g") potions = Math.min(5, potions + 1);

Gを押すと薬を1個増やします。Math.min(5, potions + 1) は5と増やした数の小さい方を選ぶので、上限は5個です。toLowerCase() で大文字と小文字を同じに扱います。

体力と薬を元に戻す
if (event.key.toLowerCase() === "r") start();

Rで start() を呼び、体力5・薬2個に戻します。薬が0個のときや体力が満タンのときは使わず、個数も減りません。

"use strict";

const canvas = document.querySelector("#game-canvas");
const ctx = canvas.getContext("2d");

let hp, potions;

function start() {
  hp = 5; potions = 2;
}

function update() {

}

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "#26334a";
  ctx.font = "28px sans-serif";
  ctx.fillText("体力: " + hp + " / 10", 230, 150);
  ctx.fillText("回復薬: " + potions, 230, 210);
  ctx.fillText("1: 使う　G: 拾う　R: 最初から", 120, 300);
}

window.addEventListener("keydown", event => {
  if (event.ctrlKey || event.altKey || event.metaKey || event.isComposing) return;
  if (event.repeat) return;
  if (event.key === "1" && potions > 0 && hp < 10) { hp = Math.min(10, hp + 3); potions -= 1; }
  if (event.key.toLowerCase() === "g") potions = Math.min(5, potions + 1);
  if (event.key.toLowerCase() === "r") start();
});

function gameLoop() {
  update();
  draw();
  requestAnimationFrame(gameLoop);
}

start();
gameLoop();

自分のゲームに組み込むには

potions と自分のゲームの体力・上限を使い、薬があるときだけ使って数を減らします。拾った物は地図や配列から1回だけ取り除き、同じ物を繰り返し拾えないようにします。

見本の状態、入力、更新、描画を自分のゲームの名前に合わせて移します。すでにある start()、update()、draw() に必要な部分を加え、ゲームループは増やしません。やり直すときは追加した状態も初期化してください。

操作：1:使う、G:拾う、R:最初から。
