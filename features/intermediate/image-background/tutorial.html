背景画像を作る

コードの比較の読み方

比較欄では消す行、追加する行、そのままの行を色とラベルで示します。変更のない途中の行を省略することがあります。比較欄は読むためのもので、コピーする欄ではありません。

− 消す＋ 追加そのまま

置き換えるときは、赤い行だけを消すのではなく、指定された変更前の範囲すべてをコピー用のコードに置き換えます。そのままの行もコピー用のコードに含まれます。古い関数を残して同じ名前の関数を追加しないでください。

コピーするのは「コピー用」と書かれたコード欄です。比較の記号はコードに入りません。

変更前を探し、変更後のコードに置き換えて保存し、index.html を開き直します。

画像を読み込む関数を用意する

変数の行の下で、次の目印のすぐ下に追加します。

目印

let asset, cover;

追加するコード

function loadImage(src) {
  const image = new Image();
  const asset = {image, status: "loading"};

}

new Image() は画像を扱うためのものを作ります。asset に画像と読込中の状態をまとめ、return で呼び出し元へ返します。まだ読み込む先を設定していないため、次の作業を続けます。

読込完了を記録する

loadImage() の状態を作る行の下で、次の目印のすぐ下に追加します。

目印

  const asset = {image, status: "loading"};

追加するコード

  image.onload = () => { asset.status = image.naturalWidth > 0 && image.naturalHeight > 0 ? "ready" : "error"; };

onload は読み込みが終わったときに動きます。> はより大きい、&& は両方の条件が必要という意味です。幅と高さが 0 より大きければ ready、そうでなければ error にします。

読込失敗を記録する

onload の行の下で、次の目印のすぐ下に追加します。

目印

  image.onload = () => { asset.status = image.naturalWidth > 0 && image.naturalHeight > 0 ? "ready" : "error"; };

追加するコード

  image.onerror = () => { asset.status = "error"; };

onerror は読み込めなかったときに動き、状態を error にします。

画像の読み込みを始める

onerror の行の下で、次の目印のすぐ下に追加します。

目印

  image.onerror = () => { asset.status = "error"; };

追加するコード

src に画像の場所を渡すと読み込みが始まります。

ステップ 2：収める方法と埋める方法

目標

収める方法と埋める方法。

小さな作業

上から順に作業します。目印を探し、その下のコードを書きます。

画像の比率を保つ倍率を決める

draw() の背景画像を描く行で、次の範囲を置き換えます。

置き換える範囲

    ctx.drawImage(asset.image, 0, 0, 800, 450);

置き換えるコード

    const scale = cover ? Math.max(800 / asset.image.naturalWidth, 450 / asset.image.naturalHeight) : Math.min(800 / asset.image.naturalWidth, 450 / asset.image.naturalHeight);
    const width = asset.image.naturalWidth * scale, height = asset.image.naturalHeight * scale;
    ctx.drawImage(asset.image, 0, 0, width, height);

画面幅と高さを元画像の幅と高さで割り、元画像の幅と高さに同じ倍率を掛けます。cover が真なら大きい倍率で画面を埋め、偽なら小さい倍率で画像全体を収めます。埋めると画面からはみ出す部分が切れます。

表示方法の背景を描く

人を描く行の下で、次の目印のすぐ下に追加します。

追加するコード

  ctx.fillStyle = "#ffffff"; ctx.fillRect(60, 40, 550, 36);
  ctx.fillStyle = "#26334a"; ctx.font = "22px sans-serif";

文字が背景に重ならないよう白い帯を描き、文字の色と大きさを決めます。

現在の表示方法を示す

表示方法の切り替えを案内する

draw() の操作案内で、次の範囲を置き換えます。

置き換える範囲

  ctx.fillStyle = "#26334a"; ctx.font = "22px sans-serif"; ctx.fillText("R: 読み直す", 90, 410);

置き換えるコード

C で切り替える操作を加えます。

Cで表示方法を切り替える

キー入力処理の R の判定と閉じ括弧の間で、次の範囲を置き換えます。

置き換える範囲

  if (event.key.toLowerCase() === "r") { start(); return; }

});

  if (event.key.toLowerCase() === "r") { start(); return; }
