敵やアイテムの出現を作る

コードの比較の読み方

比較欄は読むための表示です。消す行と追加する行を色と名前で示します。コピーするのは「変更後（コピー用）」の欄です。

− 消す＋ 追加そのまま

この教材では、変更前の script.js 全体を変更後の全体に置き換えます。前のコードを残して重ねて追加しないでください。

始める前に

ひな型をダウンロード（ZIP）

ZIPを展開してできたフォルダーでindex.htmlを開きます。ZIPにはひな型の3ファイルが入っています。

準備と操作を参考に、作業用フォルダーを用意します。この教材ではそのフォルダーの script.js を編集し、保存後に同じフォルダーの index.html を開くか再読み込みします。

ステップ 1：Spaceで1個出し上限10個

目標

Spaceで1個出し上限10個。

予想してみる

答えを確認する

小さな作業

= は右の値を左へ入れる代入です。[] は空の配列で、最初は何も出ていません。

数を表示する

draw() の画面を消す行の下で、次の目印のすぐ下に追加します。

目印

  ctx.clearRect(0, 0, canvas.width, canvas.height);

追加するコード

  ctx.fillStyle = "#26334a";
  ctx.font = "28px sans-serif";
  ctx.fillText("数: " + items.length + " / 10", 200, 90);

色と文字の大きさを決め、items.length で配列の数を取り出して表示します。上限は 10 個です。

出現した数だけ四角を描く

数の表示の下で、次の目印のすぐ下に追加します。

目印

  ctx.fillText("数: " + items.length + " / 10", 200, 90);

追加するコード

  for (let i = 0; i < items.length; i++) {
    ctx.fillStyle = "#4b8191"; ctx.fillRect(100 + i * 55, 180, 40, 40);
  }

for は i を 0 から始め、数より小さい間に 1 ずつ増やします。四角は横 100、155、210 のように 55 ずつずらして並びます。幅と高さは 40 です。

追加と再開を案内する

for の閉じ波括弧の下で、次の目印のすぐ下に追加します。

目印

  }

追加するコード

  ctx.fillStyle = "#26334a"; ctx.fillText("Space: 追加　R: 最初から", 140, 320);

Space で追加、R で最初から始める案内を表示します。

キー入力を受け取る

draw() の後、gameLoop() の先頭行の前で、次の目印のすぐ上に追加します。

目印

function gameLoop() {

追加するコード

window.addEventListener("keydown", event => {
  if (event.ctrlKey || event.altKey || event.metaKey || event.isComposing) return;
  if (event.code === "Space") event.preventDefault();

keydown はキーを押したときに起きます。|| はどれか一つが成り立つという意味です。修飾キーや日本語入力中、繰り返し入力を除き、Space でのスクロールを防ぎます。

Spaceで1個追加する

キー入力処理の繰り返しを除く行の下で、次の目印のすぐ下に追加します。

目印

  if (event.repeat) return;

追加するコード

  if (event.code === "Space") { if (items.length < 10) items.push({born: performance.now()}); }

=== は同じか、< 10 は 10 未満かを調べます。10 個未満なら push で 1 個追加し、performance.now() で出現時刻をミリ秒で記録します。

Rで空に戻す

Space の判定の下で、次の目印のすぐ下に追加します。

目印

  if (event.code === "Space") { if (items.length < 10) items.push({born: performance.now()}); }

追加するコード

  if (event.key.toLowerCase() === "r") start();

toLowerCase() で小文字にしたキーが R なら、start() で配列を空にします。

保存して作業用の index.html を再読み込みし、Space で四角が増え、10 個を超えず、R で空に戻ることを確かめます。

ステップ 2：1秒ごとに自動で出現

目標

1秒ごとに自動で出現。

予想してみる

出現間隔は？

答えを確認する

1000ミリ秒、つまり1秒です。

小さな作業

上から順に作業します。目印を探し、その下のコードを書きます。

次の出現時刻を覚える

変数の宣言で、次の範囲を置き換えます。

置き換える範囲

let items;

置き換えるコード

let items; let nextSpawn;

nextSpawn は次に自動で出す時刻です。

1秒後に出るよう準備する

start() の中で、次の範囲を置き換えます。

置き換える範囲

  items = [];

置き換えるコード

  items = []; nextSpawn = performance.now() + 1000;

空にした後、次の出現時刻を現在から 1000 ミリ秒後にします。

現在時刻を調べる

update() の中で、次の範囲を置き換えます。

置き換える範囲

function update() {

}

置き換えるコード

function update() {
  const now = performance.now();
}

更新のたびに現在時刻を now に入れます。次の作業で出現時刻と比べます。

1秒ごとに追加する

現在時刻を求める行の下で、次の目印のすぐ下に追加します。

目印

  const now = performance.now();

追加するコード

  if (now >= nextSpawn) { if (items.length < 10) items.push({born: performance.now()}); nextSpawn = now + 1000; }

>= は以上です。出現時刻になり、数が 10 未満なら追加します。数が上限でも次の時刻を現在から 1 秒後に更新します。

保存して再読み込みし、待つと約 1 秒ごとに四角が増え、10 個で止まることを確かめます。

変更前後の比較と以前の説明を見る

読むための抜粋です。編集には下のコピー用コードを使います。

次に出す時刻を決める
items = []; nextSpawn = performance.now() + 1000;

nextSpawn は次に出す時刻です。開始時は現在から1000ミリ秒、つまり1秒後にします。

時刻に達したら1個出す
if (now >= nextSpawn) { if (items.length < 10) items.push({born: performance.now()}); nextSpawn = now + 1000; }

現在時刻 now が期限以上になったら、10個未満のときに1個加えます。次の期限は今から1000ミリ秒後に設定します。

ステップ 3：出現から3秒で消しRで初期化

目標

出現から3秒で消しRで初期化。

予想してみる

生まれて3000ミリ秒ちょうどの箱は？

答えを確認する

残す条件を満たさないので消えます。

小さな作業

上から順に作業します。目印を探し、その下のコードを書きます。

3秒たったものを消す

update() の現在時刻を求める行の下で、次の目印のすぐ下に追加します。

目印

  const now = performance.now();

追加するコード

  items = items.filter(item => now - item.born < 3000);

filter は条件に合う要素を残した新しい配列を作ります。現在時刻と出現時刻の差が 3000 ミリ秒未満のものを残すので、ちょうど 3 秒になったものは消えます。

保存して再読み込みし、四角が約 3 秒で消え、自動追加と入れ替わることを確かめます。

変更前後の比較と以前の説明を見る

読むための抜粋です。編集には下のコピー用コードを使います。

3秒たった箱を除く
items = items.filter(item => now - item.born < 3000);

各要素の born は出現時刻です。今の時刻から引き、filter で生まれてから3000ミリ秒未満の箱だけを残します。ちょうど3000ミリ秒になった箱は残りません。

次の出現を今から数える
if (now >= nextSpawn) { if (items.length < 10) items.push({born: performance.now()}); nextSpawn = now + 1000; }

期限に達した更新では最大1個だけ追加し、次の時刻を現在から1秒後にします。長い停止の後に過去の分をまとめて大量発生させません。

Rでやり直す
if (event.key.toLowerCase() === "r") start();

Rで start() を呼び、箱を空にし、次の出現時刻を設定し直します。

"use strict";

const canvas = document.querySelector("#game-canvas");
const ctx = canvas.getContext("2d");

let items; let nextSpawn;

function start() {
  items = []; nextSpawn = performance.now() + 1000;
}

function update() {
  const now = performance.now();
  items = items.filter(item => now - item.born < 3000);
  if (now >= nextSpawn) { if (items.length < 10) items.push({born: performance.now()}); nextSpawn = now + 1000; }
}

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "#26334a";
  ctx.font = "28px sans-serif";
  ctx.fillText("数: " + items.length + " / 10", 200, 90);
  for (let i = 0; i < items.length; i++) {
    ctx.fillStyle = "#4b8191"; ctx.fillRect(100 + i * 55, 180, 40, 40);
  }
  ctx.fillStyle = "#26334a"; ctx.fillText("Space: 追加　R: 最初から", 140, 320);
}

window.addEventListener("keydown", event => {
  if (event.ctrlKey || event.altKey || event.metaKey || event.isComposing) return;
  if (event.code === "Space") event.preventDefault();
  if (event.repeat) return;
  if (event.code === "Space") { if (items.length < 10) items.push({born: performance.now()}); }
  if (event.key.toLowerCase() === "r") start();
});

function gameLoop() {
  update();
  draw();
  requestAnimationFrame(gameLoop);
}

start();
gameLoop();

小さな練習

filterの now - item.born < 3000 の3000を2000に変えます。最初にSpaceで1個出すと、自動出現も含めて2秒後は合計2個になることを確かめます。3000に戻します。

自分のゲームに組み込むには

items と nextSpawn を自分のゲームの状態に加えます。プレイ中だけ出現と寿命の更新を行い、上限・期限・再開始時の配列初期化も一緒に移します。

見本の状態、入力、更新、描画を自分のゲームの名前に合わせて移します。すでにある start()、update()、draw() に必要な部分を加え、ゲームループは増やしません。やり直すときは追加した状態も初期化してください。

操作：Space:1個追加、R:最初から。
