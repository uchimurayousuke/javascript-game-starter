体力バーを作る

コードの比較の読み方

比較欄では消す行、追加する行、そのままの行を色とラベルで示します。変更のない途中の行を省略することがあります。比較欄は読むためのもので、コピーする欄ではありません。

− 消す＋ 追加そのまま

置き換えるときは、赤い行だけを消すのではなく、指定された変更前の範囲すべてをコピー用のコードに置き換えます。そのままの行もコピー用のコードに含まれます。古い関数を残して同じ名前の関数を追加しないでください。

コピーするのは「コピー用」と書かれたコード欄です。比較の記号はコードに入りません。

変更前を探し、変更後のコードに置き換えて保存し、index.html を開き直します。

ステップ 2：ダメージと回復を加える

目標

ダメージと回復を加える。

小さな作業

上から順に作業します。目印を探し、その下のコードを書きます。

操作を案内する

体力を表示する行の下で、次の目印のすぐ下に追加します。

目印

  ctx.fillText("HP（残り体力） " + hp + " / " + maxHp, 120, 100);

追加するコード

  ctx.fillText("D: 30ダメージ / H: 20回復 / R: 再開", 120, 260);

D で 30 減らし、H で 20 回復し、R で再開する操作を示します。

Dキーで体力を減らす

キー入力処理の R キーの判定と閉じ括弧の間で、次の範囲を置き換えます。

置き換える範囲

  if (event.key.toLowerCase() === "r") { start(); return; }

});

置き換えるコード

  if (event.key.toLowerCase() === "r") { start(); return; }
  if (event.key.toLowerCase() === "d") hp = Math.max(0, hp - 30);
});

Math.max(0, hp - 30) は 0 と減らした値の大きい方です。残り 20 なら 0 になり、負の値にはなりません。

Hキーで体力を回復する

D キーの判定の下で、次の目印のすぐ下に追加します。

目印

  if (event.key.toLowerCase() === "d") hp = Math.max(0, hp - 30);

追加するコード

  else if (event.key.toLowerCase() === "h") hp = Math.min(maxHp, hp + 20);

else if は前の条件が成り立たず、次の条件が成り立つときに実行します。Math.min は最大体力と増やした値の小さい方を選び、100 を超えないようにします。

保存して再読み込みし、D で体力が 30 減り、H で 20 回復し、0 と 100 の範囲に収まることを確かめます。

"use strict";

const canvas = document.querySelector("#game-canvas");
const ctx = canvas.getContext("2d");

const maxHp = 100;
let hp;

function start() {
  hp = maxHp;
}

function update() {

}

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "#26334a"; ctx.font = "28px sans-serif";
  ctx.fillText("HP（残り体力） " + hp + " / " + maxHp, 120, 100);
  ctx.fillText("D: 30ダメージ / H: 20回復 / R: 再開", 120, 260);
}

window.addEventListener("keydown", event => {
  if (event.repeat) return;
  if (event.key.toLowerCase() === "r") { start(); return; }
  if (event.key.toLowerCase() === "d") hp = Math.max(0, hp - 30);
  else if (event.key.toLowerCase() === "h") hp = Math.min(maxHp, hp + 20);
});

function gameLoop() {
  update();
  draw();
  requestAnimationFrame(gameLoop);
}

start();
gameLoop();

体力バーを描く。

小さな作業

バーの背景を描く

draw() の体力表示の下で、次の目印のすぐ下に追加します。

目印

  ctx.fillText("HP（残り体力） " + hp + " / " + maxHp, 120, 100);

追加するコード

  ctx.fillStyle = "#dce8ef"; ctx.fillRect(120, 150, 300, 30);

fillRect は左から 120、上から 150 の位置に幅 300、高さ 30 の四角を描きます。これがバー全体の背景です。

残り体力の割合を描く

バーの背景を描く行の下で、次の目印のすぐ下に追加します。

目印

  ctx.fillStyle = "#dce8ef"; ctx.fillRect(120, 150, 300, 30);

追加するコード

  ctx.fillStyle = "#3f9b68"; ctx.fillRect(120, 150, 300 * hp / maxHp, 30);

幅は 300 * hp / maxHp です。体力が 50 / 100 なら 150、0 なら 0 になります。* は掛け算、/ は割り算です。
