タイトルとメニューを作る

コードの比較の読み方

比較欄では消す行、追加する行、そのままの行を色とラベルで示します。変更のない途中の行を省略することがあります。比較欄は読むためのもので、コピーする欄ではありません。

− 消す＋ 追加そのまま

置き換えるときは、赤い行だけを消すのではなく、指定された変更前の範囲すべてをコピー用のコードに置き換えます。そのままの行もコピー用のコードに含まれます。古い関数を残して同じ名前の関数を追加しないでください。

コピーするのは「コピー用」と書かれたコード欄です。比較の記号はコードに入りません。

目標

ゲームの位置とキーを記録する

ファイルの先頭近くで、次の範囲を置き換えます。

置き換える範囲

let state, selected;

置き換えるコード

let state, selected, gameX, keys;

gameX は四角の横位置、keys は押しているキーを記録します。

ゲーム開始時の状態を作る

変数の行の下で、次の目印のすぐ下に追加します。

目印

let state, selected, gameX, keys;

追加するコード

function startGame() { state = "game"; gameX = 100; keys = {}; }

startGame() は画面をゲームに切り替え、横位置を 100 にし、キーの記録を空にします。

左右への移動を用意する

startGame() の下で、次の目印のすぐ下に追加します。

目印

function startGame() { state = "game"; gameX = 100; keys = {}; }

追加するコード

function updateGame() {
  gameX += (keys.ArrowRight ? 3 : 0) - (keys.ArrowLeft ? 3 : 0);
  gameX = Math.max(20, Math.min(780, gameX));
}

右キーなら 3 を足し、左キーなら 3 を引きます。+= は今の値に右側を足します。Math.min と Math.max で横位置を 20 から 780 に収めます。

ゲーム画面を描く

updateGame() の後で、次の目印のすぐ下に追加します。

目印

function updateGame() {
  gameX += (keys.ArrowRight ? 3 : 0) - (keys.ArrowLeft ? 3 : 0);
  gameX = Math.max(20, Math.min(780, gameX));
}

追加するコード

function drawGame() {
  ctx.fillStyle = "#26334a"; ctx.font = "28px sans-serif";
  ctx.fillText("ゲーム中　←→: 移動", 160, 150);
  ctx.fillStyle = "#397ab4"; ctx.fillRect(gameX - 20, 230, 40, 40);
}

文字と青い四角を描きます。四角の左端を gameX - 20 にするので、幅 40 の中央が gameX です。

keydown はキーを押したときに起きます。押し続けた繰り返しは return で除き、R で最初に戻します。

上下キーで選択する

キー入力処理の中で、次の目印のすぐ下に追加します。

目印

  if (event.key.toLowerCase() === "r") { start(); return; }

追加するコード

  if (state === "menu") {
    if (event.key === "ArrowUp" || event.key === "ArrowDown") { event.preventDefault(); selected = 1 - selected; }
  }

|| はどちらか一方が成り立つという意味です。上下キーを押すと 1 - selected が 0 と 1 を切り替えます。preventDefault() は矢印キーによるページのスクロールを防ぎます。

Enter で決定する

上下キーの判定の下で、次の目印のすぐ下に追加します。

目印

    if (event.key === "ArrowUp" || event.key === "ArrowDown") { event.preventDefault(); selected = 1 - selected; }

追加するコード

    else if (event.key === "Enter") { if (selected === 0) startGame(); else state = "help"; }

Enter を押したら、選択が 0 ならゲームを開始し、1 なら遊び方の画面に切り替えます。

ゲーム中の左右キーを記録する

メニューの判定の閉じ波括弧の下で、次の目印のすぐ下に追加します。

目印

    else if (event.key === "Enter") { if (selected === 0) startGame(); else state = "help"; }
  }

追加するコード

  else if (state === "game" && (event.key === "ArrowLeft" || event.key === "ArrowRight")) { event.preventDefault(); keys[event.key] = true; }

&& は両方の条件が必要という意味です。ゲーム中に左右キーを押すと、キーの名前を使って keys に true を記録します。

キーを離したときの記録を消す

keydown の処理の直後で、次の目印のすぐ下に追加します。

目印

});

追加するコード

keyup はキーを離したときに起き、左右キーの記録を false にします。

画面から離れたときも記録を消す

keyup の処理の下で、次の目印のすぐ下に追加します。

目印

"use strict";

const canvas = document.querySelector("#game-canvas");

let state, selected, gameX, keys;
function startGame() { state = "game"; gameX = 100; keys = {}; }
function updateGame() {
  gameX += (keys.ArrowRight ? 3 : 0) - (keys.ArrowLeft ? 3 : 0);
  gameX = Math.max(20, Math.min(780, gameX));
}
function drawGame() {
  ctx.fillStyle = "#26334a"; ctx.font = "28px sans-serif";
  ctx.fillText("ゲーム中　←→: 移動", 160, 150);
  ctx.fillStyle = "#397ab4"; ctx.fillRect(gameX - 20, 230, 40, 40);
}

function start() {
  state = "menu"; selected = 0; gameX = 100; keys = {};
}

function update() {
  if (state === "game") updateGame();
}

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "#26334a"; ctx.font = "30px sans-serif";
  if (state === "menu") {
    ctx.fillText("ゲームメニュー", 260, 100);
    for (let i = 0; i < 2; i++) {
      ctx.fillStyle = selected === i ? "#f8dc8b" : "#dce8ef";
      ctx.fillRect(250, 150 + i * 80, 300, 60);
      ctx.fillStyle = "#26334a"; ctx.fillText(i === 0 ? "はじめる" : "遊び方", 320, 190 + i * 80);
    }
    ctx.fillText(selected === 0 ? "選択中: はじめる" : "選択中: 遊び方", 260, 350);
    ctx.font = "22px sans-serif"; ctx.fillText("↑↓で選択 / Enterで決定", 180, 410);
  } else if (state === "game") drawGame();

  if (event.repeat) return;
  if (event.key.toLowerCase() === "r") { start(); return; }

変更 5：クリックした項目を開く

次は説明用の抜粋です。編集するときは、この後の「比較とコピー用コード」を開き、変更前の範囲を変更後の全体に置き換えます。

クリック位置をCanvasの座標に変える

メニュー画面のクリックだけを調べます。

if (state !== "menu") return;
const rect = canvas.getBoundingClientRect();
const x = (event.clientX - rect.left) * canvas.width / rect.width;
const y = (event.clientY - rect.top) * canvas.height / rect.height;

!== は「同じではない」なので、メニュー以外なら処理を終えます。rect は画面上のCanvasの位置と大きさです。クリック位置から左上を引き、実際の幅・高さと表示上の幅・高さの比を掛けると、Canvas内の座標になります。横幅800を400で表示している場合、表示上の左端から100の場所はCanvas内の x = 200 です。 クリック座標の図も確認できます。

2つの項目がある範囲を調べる

クリックがメニューの横幅と縦の範囲に入っているか調べます。

if (x >= 250 && x < 550 && y >= 150 && y < 290) {
  const i = Math.floor((y - 150) / 80);

x は250以上550未満、y は150以上290未満を調べます。&& はすべての条件が必要です。縦位置から150を引いて80で割り、小数点以下を切り捨てると、上の項目は0、下の項目は1になります。

項目のすき間を除いて決定する

四角の内側なら、その項目を選びます。

if (y < 210 + i * 80) { selected = i; if (i === 0) startGame(); else state = "help"; }

上の四角は y が150以上210未満、下は230以上290未満です。y < 210 + i * 80 で間の20ピクセルを除きます。項目0ならゲームを始め、1なら遊び方を開きます。

"use strict";

const canvas = document.querySelector("#game-canvas");
const ctx = canvas.getContext("2d");

let state, selected, gameX, keys;
function startGame() { state = "game"; gameX = 100; keys = {}; }
function updateGame() {
  gameX += (keys.ArrowRight ? 3 : 0) - (keys.ArrowLeft ? 3 : 0);
  gameX = Math.max(20, Math.min(780, gameX));
}
function drawGame() {
  ctx.fillStyle = "#26334a"; ctx.font = "28px sans-serif";
  ctx.fillText("ゲーム中　←→: 移動 / Esc: 戻る", 160, 150);
  ctx.fillStyle = "#397ab4"; ctx.fillRect(gameX - 20, 230, 40, 40);
}

function start() {
  state = "menu"; selected = 0; gameX = 100; keys = {};
}

function update() {
  if (state === "game") updateGame();
}

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "#26334a"; ctx.font = "30px sans-serif";
  if (state === "menu") {
    ctx.fillText("ゲームメニュー", 260, 100);
    for (let i = 0; i < 2; i++) {
      ctx.fillStyle = selected === i ? "#f8dc8b" : "#dce8ef";
      ctx.fillRect(250, 150 + i * 80, 300, 60);
      ctx.fillStyle = "#26334a"; ctx.fillText(i === 0 ? "はじめる" : "遊び方", 320, 190 + i * 80);
    }
    ctx.fillText(selected === 0 ? "選択中: はじめる" : "選択中: 遊び方", 260, 350);
    ctx.font = "22px sans-serif"; ctx.fillText("↑↓で選択 / Enter・クリックで決定", 180, 410);
  } else if (state === "game") drawGame();
  else ctx.fillText("遊び方　Esc: メニューへ", 160, 200);
}

window.addEventListener("keydown", event => {
  if (event.repeat) return;
  if (event.key.toLowerCase() === "r") { start(); return; }
  if (state === "menu") {
    if (event.key === "ArrowUp" || event.key === "ArrowDown") { event.preventDefault(); selected = 1 - selected; }
    else if (event.key === "Enter") { if (selected === 0) startGame(); else state = "help"; }
  } else if (event.key === "Escape") { state = "menu"; keys = {}; }
  else if (state === "game" && (event.key === "ArrowLeft" || event.key === "ArrowRight")) { event.preventDefault(); keys[event.key] = true; }
});
window.addEventListener("keyup", event => { if (event.key === "ArrowLeft" || event.key === "ArrowRight") keys[event.key] = false; });
window.addEventListener("blur", () => { keys = {}; });
canvas.addEventListener("click", event => {
  if (state !== "menu") return;
  const rect = canvas.getBoundingClientRect();
  const x = (event.clientX - rect.left) * canvas.width / rect.width;
  const y = (event.clientY - rect.top) * canvas.height / rect.height;
  if (x >= 250 && x < 550 && y >= 150 && y < 290) {
    const i = Math.floor((y - 150) / 80);
    if (y < 210 + i * 80) { selected = i; if (i === 0) startGame(); else state = "help"; }
  }
});

function gameLoop() {
  update();
  draw();
  requestAnimationFrame(gameLoop);
}

start();
gameLoop();

自分のゲームに組み込むには

stateとselected、キーとクリックの選択処理を自作ゲームへ移します。

選択したときにstartGameを呼び、updateGameとdrawGameの中身を自分のゲームの更新と描画に置き換えます。戻るときはstateをmenuにします。

この欄のstartGame・updateGame・drawGameは、自分のゲーム側の開始・更新・描画の関数名の例です。自分の関数名に合わせて読み替えます。gameLoopは増やさず、既存のstart・update・drawから必要な処理を呼び、再挑戦では持ち込んだ状態や入力も初期化します。
