結果と再挑戦を作る

コードの比較の読み方

比較欄では消す行、追加する行、そのままの行を色とラベルで示します。変更のない途中の行を省略することがあります。比較欄は読むためのもので、コピーする欄ではありません。

− 消す＋ 追加そのまま

置き換えるときは、赤い行だけを消すのではなく、指定された変更前の範囲すべてをコピー用のコードに置き換えます。そのままの行もコピー用のコードに含まれます。古い関数を残して同じ名前の関数を追加しないでください。

コピーするのは「コピー用」と書かれたコード欄です。比較の記号はコードに入りません。

= は右の値を左の変数に入れる代入です。開始時に状態を playing、得点を 0 にします。

ゲーム中の得点を描く

draw() の画面を消す行の下で、次の目印のすぐ下に追加します。

目印

  ctx.clearRect(0, 0, canvas.width, canvas.height);

追加するコード

  ctx.fillStyle = "#26334a"; ctx.font = "28px sans-serif";
  if (state === "playing") { ctx.fillText("Spaceで得点: " + score, 180, 150); }

文字の色と大きさを決めます。if は条件が成り立つときに実行し、=== は同じかを調べます。文字列と得点は + でつなぎます。描画位置は左上を原点として横 180、縦 150 です。

結果画面を用意する

ゲーム中の表示の下で、次の目印のすぐ下に追加します。

目印

追加するコード

  else if (state === "result") { ctx.fillText("結果: " + score + "点", 200, 150); ctx.fillText("結果を表示", 180, 220); }

else if は前の条件が違うときに次の条件を調べます。result なら得点を表示します。結果画面への切り替えは次のステップで作ります。

メニュー画面を用意する

結果画面を表示する行の下で、次の目印のすぐ下に追加します。

目印

追加するコード

  else ctx.fillText("メニュー　Enter: はじめる", 180, 150);

ゲーム中でも結果でもないときはメニューを描きます。メニューへの移動は後のステップで作ります。

const canvas = document.querySelector("#game-canvas");
const ctx = canvas.getContext("2d");

let state, score;

function start() {
  state = "playing"; score = 0;
}

function update() {

}

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "#26334a"; ctx.font = "28px sans-serif";
  if (state === "playing") { ctx.fillText("Spaceで得点: " + score, 180, 150); }
  else if (state === "result") { ctx.fillText("結果: " + score + "点", 200, 150); ctx.fillText("結果を表示", 180, 220); }

}

window.addEventListener("keydown", event => {
  if (event.repeat) return;
  const key = event.key.toLowerCase();
  if (state === "playing" && event.key === " ") { event.preventDefault(); score++; if (score >= 3) state = "result"; }
});

function gameLoop() {
  update();
  draw();
  requestAnimationFrame(gameLoop);
}

この欄のstartGame・updateGame・drawGameは、自分のゲーム側の開始・更新・描画の関数名の例です。自分の関数名に合わせて読み替えます。gameLoopは増やさず、既存のstart・update・drawから必要な処理を呼び、再挑戦では持ち込んだ状態や入力も初期化します。
