残り回数とゲームオーバーを作る

コードの比較の読み方

比較欄は読むための表示です。消す行と追加する行を色と名前で示します。コピーするのは「変更後（コピー用）」の欄です。

− 消す＋ 追加そのまま

この教材では、変更前の script.js 全体を変更後の全体に置き換えます。前のコードを残して重ねて追加しないでください。

始める前に

ひな型をダウンロード（ZIP）

ZIPを展開してできたフォルダーでindex.htmlを開きます。ZIPにはひな型の3ファイルが入っています。

準備と操作を参考に、作業用フォルダーを用意します。この教材ではそのフォルダーの script.js を編集し、保存後に同じフォルダーの index.html を開くか再読み込みします。

キー入力を受け取る

draw() の後、gameLoop() の前で、次の目印のすぐ上に追加します。

目印

function gameLoop() {

追加するコード

window.addEventListener("keydown", event => {
  if (event.ctrlKey || event.altKey || event.metaKey || event.isComposing) return;
  if (event.repeat) return;
});

keydown はキーを押したときに起きます。修飾キーや日本語入力中、押し続けた繰り返しは return で処理を終えます。|| はどれか一つが成り立つという意味です。

Xで残りを減らす

キー入力処理の中で、次の目印のすぐ下に追加します。

目印

  if (event.repeat) return;

追加するコード

  if (event.key.toLowerCase() === "x") lives = Math.max(0, lives - 1);

toLowerCase() で小文字にして X を判定します。=== は左右が同じかの比較です。Math.max(0, lives - 1) は 0 と減らした値の大きい方を選び、残りが 0 未満になるのを防ぎます。

ゲーム中だけ残りを減らす

置き換える範囲

let lives, state;

  lives = 3; state = "playing";
}

function update() {

  ctx.font = "28px sans-serif";
  ctx.fillText("残り: " + lives, 250, 150);
  if (state === "over") ctx.fillText("ゲームオーバー", 250, 220);
  ctx.fillText("X: 失敗　H: 回復　R: 最初から", 170, 300);
}

window.addEventListener("keydown", event => {
  if (event.ctrlKey || event.altKey || event.metaKey || event.isComposing) return;
  if (event.repeat) return;
  if (event.key.toLowerCase() === "x" && state === "playing") {
    lives = Math.max(0, lives - 1);
    if (lives === 0) state = "over";
  }
  if (event.key.toLowerCase() === "r") start();
  if (event.key.toLowerCase() === "h" && state === "playing") lives = Math.min(3, lives + 1);
});

function gameLoop() {
  update();
  draw();
  requestAnimationFrame(gameLoop);
}

start();
gameLoop();

自分のゲームに組み込むには

lives と終了状態を自分のゲームに用意し、1回の失敗判定で1だけ減らします。キャラクターの位置だけを戻す処理と、全体の start() で残りを初期化する処理を分けます。

見本の状態、入力、更新、描画を自分のゲームの名前に合わせて移します。すでにある start()、update()、draw() に必要な部分を加え、ゲームループは増やしません。やり直すときは追加した状態も初期化してください。
