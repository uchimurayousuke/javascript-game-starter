ステップ 3：100msごとに1文字、Spaceで全文表示または次へ

目標

100msごとに1文字、Spaceで全文表示または次へ。

予想してみる

途中でSpaceを押した直後は？

答えを確認する

今の文章を最後まで表示します。

小さな作業

上から順に作業します。目印を探し、その下のコードを書きます。

表示文字数と時刻を覚える

変数の宣言で、次の範囲を置き換えます。

置き換える範囲

let index;

置き換えるコード

let index; let shown, lastAt;

shown は表示した文字の数、lastAt は文字を進めた基準時刻です。

文字送りの状態を初期化する

start() の中で、次の範囲を置き換えます。

置き換える範囲

  index = 0;

置き換えるコード

  index = 0; shown = 0; lastAt = performance.now();

最初の文章を 0 文字から始め、performance.now() で現在時刻をミリ秒で記録します。

文字を進める回数を求める

update() の中で、次の範囲を置き換えます。

置き換える範囲

function update() {

}

置き換えるコード

function update() {
  const now = performance.now();
  const count = Math.floor((now - lastAt) / 100);
}

現在時刻と基準時刻の差を 100 ミリ秒で割ります。Math.floor で小数を切り捨てるので、250 ミリ秒なら 2 文字分です。

経過した分だけ文字を増やす

count を求める行の下で、次の目印のすぐ下に追加します。

目印

  const count = Math.floor((now - lastAt) / 100);

追加するコード

  if (count > 0) {
    shown = Math.min(messages[index].length, shown + count);
    lastAt += count * 100;
  }

> 0 は 0 より大きいという意味です。文字数を増やし、Math.min で文章の長さを超えないようにします。+= は今の値に足す書き方で、基準時刻を進めて余った時間を次に残します。

表示する文字数を反映する

draw() の文章表示で、次の範囲を置き換えます。

置き換える範囲

  ctx.fillText(messages[index], 180, 180);

置き換えるコード

  ctx.fillText(messages[index].slice(0, shown), 180, 180);

slice(0, shown) は先頭から shown 文字分を取り出します。

文字送りと再開を案内する

draw() の案内で、次の範囲を置き換えます。

置き換える範囲

  ctx.fillText("Space: 次へ", 180, 300);

置き換えるコード

  ctx.fillText("Space: 文字送り　R: 最初から", 180, 300);

Space と R の操作を表示します。キー処理は次に変更します。

Spaceで全文表示か次の文章を選ぶ

キー入力処理の Space の判定で、次の範囲を置き換えます。

置き換える範囲

  if (event.code === "Space") { index = Math.min(index + 1, messages.length - 1); }

置き換えるコード

  if (event.code === "Space") {
    if (shown < messages[index].length) shown = messages[index].length;
    else if (index < messages.length - 1) { index += 1; shown = 0; lastAt = performance.now(); }

  }

< は左が右より小さいという意味です。表示途中なら全文を表示し、全文表示後で次の文章があれば番号を進め、文字数と時刻を初期化します。最後の文章では進みません。

Rで会話を最初に戻す

Space の判定の閉じ波括弧の下で、次の目印のすぐ下に追加します。

目印

    else if (index < messages.length - 1) { index += 1; shown = 0; lastAt = performance.now(); }

  }

追加するコード

  if (event.key.toLowerCase() === "r") start();

toLowerCase() で小文字にしたキーが R なら start() で最初の文章から始めます。

保存して再読み込みし、文字が少しずつ現れ、Space で全文表示してから次に進み、R で最初に戻ることを確かめます。

"use strict";

const canvas = document.querySelector("#game-canvas");
const ctx = canvas.getContext("2d");

const messages = ["こんにちは", "気をつけて", "またね"];
let index; let shown, lastAt;

function start() {
  index = 0; shown = 0; lastAt = performance.now();
}

function update() {
  const now = performance.now();
  const count = Math.floor((now - lastAt) / 100);
  if (count > 0) {
    shown = Math.min(messages[index].length, shown + count);
    lastAt += count * 100;
  }
}

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "#26334a";
  ctx.font = "28px sans-serif";
  ctx.fillText(messages[index].slice(0, shown), 180, 180);
  ctx.fillText("Space: 文字送り　R: 最初から", 180, 300);
}

window.addEventListener("keydown", event => {
  if (event.ctrlKey || event.altKey || event.metaKey || event.isComposing) return;
  if (event.code === "Space") event.preventDefault();
  if (event.repeat) return;
  if (event.code === "Space") {
    if (shown < messages[index].length) shown = messages[index].length;
    else if (index < messages.length - 1) { index += 1; shown = 0; lastAt = performance.now(); }

  }
  if (event.key.toLowerCase() === "r") start();
});

function gameLoop() {
  update();
  draw();
  requestAnimationFrame(gameLoop);
}

start();
gameLoop();

自分のゲームに組み込むには

messages、index、shown、lastAt を会話の状態として持ちます。update() に文字数の更新、draw() に表示を入れ、会話中の進む操作で全文表示と次の文章を切り替えます。

見本の状態、入力、更新、描画を自分のゲームの名前に合わせて移します。すでにある start()、update()、draw() に必要な部分を加え、ゲームループは増やしません。やり直すときは追加した状態も初期化してください。
