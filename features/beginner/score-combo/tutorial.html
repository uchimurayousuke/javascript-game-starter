得点とコンボを作る

コードの比較の読み方

比較欄は読むための表示です。消す行と追加する行を色と名前で示します。コピーするのは「変更後（コピー用）」の欄です。

− 消す＋ 追加そのまま

この教材では、変更前の script.js 全体を変更後の全体に置き換えます。前のコードを残して重ねて追加しないでください。

始める前に

ひな型をダウンロード（ZIP）

ZIPを展開してできたフォルダーでindex.htmlを開きます。ZIPにはひな型の3ファイルが入っています。

準備と操作を参考に、作業用フォルダーを用意します。この教材ではそのフォルダーの script.js を編集し、保存後に同じフォルダーの index.html を開くか再読み込みします。

ステップ 1：スペースを押すたび得点10

目標

スペースを押すたび得点10。

予想してみる

1回押したら何点？

答えを確認する

10点です。

小さな作業

上から順に作業します。目印を探し、その下のコードを書きます。

得点を覚える

作業用の script.js の先頭近くで、次の目印のすぐ下に追加します。

目印

const ctx = canvas.getContext("2d");

追加するコード

let score;

let は後で値を変えられる変数を作ります。score に得点を覚えます。

得点を0から始める

start() から update() の閉じ波括弧までで、次の範囲を置き換えます。

置き換える範囲

function start() {
}

function update() {
}

置き換えるコード

function start() {
  score = 0;
}

function update() {

}

= は右の値を左の変数に入れる代入です。開始時に得点を 0 にします。

得点を表示する

draw() の画面を消す行の下で、次の目印のすぐ下に追加します。

目印

  ctx.clearRect(0, 0, canvas.width, canvas.height);

追加するコード

  ctx.fillStyle = "#26334a";
  ctx.font = "28px sans-serif";
  ctx.fillText("得点: " + score, 250, 150);

色と文字の大きさを決め、文字列と得点を + でつなぎます。fillText の座標は左上を原点として横 250、縦 150 です。

成功の操作を案内する

得点の表示の下で、次の目印のすぐ下に追加します。

目印

  ctx.fillText("得点: " + score, 250, 150);

追加するコード

  ctx.fillText("Space: 成功　", 160, 300);

Space で成功することを画面に表示します。

キー入力を受け取る

draw() の後、gameLoop() の先頭行の前で、次の目印のすぐ上に追加します。

目印

function gameLoop() {

追加するコード

window.addEventListener("keydown", event => {
  if (event.ctrlKey || event.altKey || event.metaKey || event.isComposing) return;
  if (event.code === "Space") event.preventDefault();
  if (event.repeat) return;
});

keydown はキーを押したときに起きます。|| はどれか一つが成り立つという意味です。修飾キーや日本語入力中は return で終え、Space でのスクロールを防ぎます。押し続けた繰り返しも除きます。

Spaceで得点を増やす

キー入力処理の繰り返しを除く行の下で、次の目印のすぐ下に追加します。

目印

  if (event.repeat) return;

追加するコード

  if (event.code === "Space") { score += 10; }

=== でキーが Space か調べます。+= 10 は今の得点に 10 を足します。

保存して作業用の index.html を再読み込みし、Space を押すたび得点が 10 点増えることを確かめます。

ステップ 2：連続で成功するとコンボ倍率を増やす

目標

連続で成功するとコンボ倍率を増やす。

予想してみる

2回目に増える得点は？

答えを確認する

コンボ2なので20点です。

小さな作業

上から順に作業します。目印を探し、その下のコードを書きます。

連続成功を覚える

変数の宣言で、次の範囲を置き換えます。

置き換える範囲

let score;

置き換えるコード

let score, combo;

combo は連続成功の回数を覚えます。

コンボを0から始める

start() の中で、次の範囲を置き換えます。

置き換える範囲

  score = 0;

置き換えるコード

  score = 0; combo = 0;

得点と連続成功の回数をどちらも 0 にします。

コンボを表示する

得点表示の下で、次の目印のすぐ下に追加します。

目印

  ctx.fillText("得点: " + score, 250, 150);

追加するコード

  ctx.fillText("コンボ: " + combo, 250, 210);

得点の下に連続成功の回数を表示します。

連続成功で得点を増やす

Space キーの判定で、次の範囲を置き換えます。

置き換える範囲

  if (event.code === "Space") { score += 10; }

置き換えるコード

  if (event.code === "Space") { combo += 1; score += 10 * combo; }

成功すると先にコンボを 1 増やし、10 * combo を得点に足します。* は掛け算です。1 回目は 10 点、2 回目は 20 点を加え、合計 30 点になります。

保存して再読み込みし、Space を 2 回押すとコンボが 2、得点が 30 になることを確かめます。

現在のコンボを横250・縦210に描きます。

ステップ 3：Fでコンボを切り、Rでやり直す

目標

Fでコンボを切り、Rでやり直す。

予想してみる

Fで得点も0になる？

答えを確認する

なりません。コンボだけが0になります。

小さな作業

上から順に作業します。目印を探し、その下のコードを書きます。

失敗と再開の操作を案内する

draw() の操作案内で、次の範囲を置き換えます。

置き換える範囲

  ctx.fillText("Space: 成功　", 160, 300);

置き換えるコード

  ctx.fillText("Space: 成功　F: 失敗　R: 最初から", 160, 300);

F で失敗、R で最初から始める操作を表示します。

失敗でコンボを戻す

キー入力処理の Space の判定の下で、次の目印のすぐ下に追加します。

目印

  if (event.code === "Space") { combo += 1; score += 10 * combo; }

追加するコード

  if (event.key.toLowerCase() === "f") combo = 0;

toLowerCase() でキーを小文字にし、F ならコンボを 0 に戻します。得点は残ります。

Rで最初から始める

F の判定の下で、次の目印のすぐ下に追加します。

目印

  if (event.key.toLowerCase() === "f") combo = 0;

追加するコード

  if (event.key.toLowerCase() === "r") start();

R なら start() で得点とコンボを 0 に戻します。

保存して再読み込みし、F でコンボが 0 に戻って得点は残り、R で両方が 0 になることを確かめます。

Fを押すとコンボだけを0にします。score は変わらないので、得点は残ります。toLowerCase() でキー名を小文字にして比べます。

Rを押すと start() が得点とコンボの両方を0に戻します。

const canvas = document.querySelector("#game-canvas");

}

function update() {

自分のゲームに組み込むには

score と combo を自分のゲームの状態に用意します。実際の成功判定でコンボを増やして加点し、失敗判定ではコンボだけを0にします。全体の再開始では両方を0にします。

見本の状態、入力、更新、描画を自分のゲームの名前に合わせて移します。すでにある start()、update()、draw() に必要な部分を加え、ゲームループは増やしません。やり直すときは追加した状態も初期化してください。
