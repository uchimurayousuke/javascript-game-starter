ステップ 1：Spaceで得点を10増やし、Lでレベルを1増やす

目標

Spaceで得点を10増やし、Lでレベルを1増やす。

予想してみる

Spaceを3回、Lを1回押すと？

答えを確認する

得点30・レベル2です。

この段階で変えるところ

次は説明用の抜粋です。編集するときは、後の「比較とコピー用コード」を開き、変更後のコード全体を使います。

得点とレベルを初期化する

let score, level, message, loadVersion = 0;

function start() {
  score = 0; level = 1; message = ""; loadVersion += 1;
}

score は得点、level はレベル、message は案内の文字です。start() で得点0、レベル1、案内なしに戻します。loadVersion は読み込みの新しさを表す番号で、後のステップで使います。

SpaceとLで値を増やす

if (event.code === "Space") { score = Math.min(999, score + 10); loadVersion += 1; }
if (event.key.toLowerCase() === "l") { level = Math.min(10, level + 1); loadVersion += 1; }

Spaceなら得点に10を足し、Math.min で999を上限にします。Lならレベルに1を足し、10を上限にします。値を更新するたびに loadVersion も1増やします。Rは start() を呼びます。

入力欄の操作と押しっぱなしを区別する

if (event.target && (event.target.tagName === "INPUT" || event.target.tagName === "BUTTON")) return;

入力欄やボタンを操作したときは、ゲーム用のキー処理を行いません。修飾キーや文字の変換中も処理せず、event.repeat で押しっぱなしの自動繰り返しを除きます。

"use strict";

const canvas = document.querySelector("#game-canvas");

function start() {
  score = 0; level = 1; message = ""; loadVersion += 1;

function update() {

}

  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "#26334a";
  ctx.font = "28px sans-serif";

  ctx.font = "22px sans-serif"; ctx.fillText(message, 140, 330);
}

  if (event.target && (event.target.tagName === "INPUT" || event.target.tagName === "BUTTON")) return;
  if (event.ctrlKey || event.altKey || event.metaKey || event.isComposing) return;
  if (event.code === "Space") event.preventDefault();
  if (event.repeat) return;

  draw();
  requestAnimationFrame(gameLoop);

ステップ 2：JSONファイルを書き出す

目標

JSONファイルを書き出す。

予想してみる

何をファイルに入れる？

答えを確認する

形式の番号、得点、レベルです。

この段階で変えるところ

次は説明用の抜粋です。編集するときは、後の「比較とコピー用コード」を開き、変更後のコード全体を使います。

保存ボタンを作る

const saveButton = document.createElement("button");
saveButton.type = "button"; saveButton.textContent = "保存する";
document.body.append(saveButton);

button を作り、「保存する」と表示してページに追加します。

保存する値をJSONの文字にする

const data = JSON.stringify({version: 1, score, level});

JSON.stringify は保存する値をJSON形式の文字列にします。version は形式の番号1、score と level はその時点の値です。たとえば得点30、レベル2なら {"version":1,"score":30,"level":2} になります。

JSONをファイルとして書き出す

const url = URL.createObjectURL(new Blob([data], {type: "application/json"}));
const link = document.createElement("a"); link.href = url; link.download = "game-save.json";

Blob はJSONの文字からファイルの中身を作り、一時URLを用意します。リンクの download にファイル名を指定し、続く処理でリンクをクリックして書き出します。

一時URLを片付ける

document.body.append(link); link.click(); link.remove();
setTimeout(() => URL.revokeObjectURL(url), 1000);

リンクを追加してクリックし、削除します。1000 ミリ秒後に一時URLを解除します。保存を知らせる文字も設定します。読み込みは次のステップで作ります。

ステップ 3：JSONファイルを選び、検証して読み込む

目標

JSONファイルを選び、検証して読み込む。

予想してみる

読めないファイルを選ぶと？

答えを確認する

現在の得点とレベルは変わりません。

この段階で変えるところ

次は説明用の抜粋です。編集するときは、後の「比較とコピー用コード」を開き、変更後のコード全体を使います。

読み込むファイルを選ぶ

const loadInput = document.createElement("input");
loadInput.type = "file"; loadInput.accept = ".json,application/json";
loadLabel.append(loadInput); document.body.append(loadLabel);

ファイルを選ぶ入力欄を作り、JSONを選ぶための種類を指定します。種類の指定だけでは中身が正しいか分からないので、後で内容も確認します。

読み込みの新しさを覚える

const file = loadInput.files[0];
if (!file) return;
const request = ++loadVersion;
loadInput.value = "";

選ばれた最初のファイルを取り出し、未選択なら処理を終えます。++loadVersion で番号を増やし、その番号を request に覚えます。入力欄を空にして、同じファイルをもう一度選べるようにします。

大きさとJSONの形式を調べる

if (file.size > 4096) throw new Error();
const data = JSON.parse(await file.text());
if (request !== loadVersion) return;

ファイルが4096バイトを超えると失敗にします。file.text() の読み込みを待ち、JSON.parse で文字列をデータに戻します。待っている間に別の読み込みや得点・レベルの変更、Rによる初期化があると番号が変わるため、古い結果を使わずに終えます。

形式と値を検証する

if (!data || typeof data !== "object" || Array.isArray(data) || Object.keys(data).sort().join(",") !== "level,score,version" || data.version !== 1 || !Number.isInteger(data.score) || data.score < 0 || data.score > 999 || !Number.isInteger(data.level) || data.level < 1 || data.level > 10) throw new Error();

|| でつないだ条件のどれかに当てはまれば失敗です。データがオブジェクトで、配列ではなく、項目が level・score・version の3つだけか調べます。version は1、得点は整数0〜999、レベルは整数1〜10である必要があります。Number.isInteger で整数かどうかを確かめます。

検証に成功した値だけ反映する

score = data.score; level = data.level; message = "読み込みました";

すべての検証を通った後で初めて得点とレベルに代入します。ファイルが大きすぎる、JSONが壊れている、項目や値が正しくないなどの失敗では catch が「読み込めませんでした」と表示し、元の得点とレベルを保ちます。古い読み込みは失敗の表示も新しい状態に上書きしません。

保存後の確認

保存したファイルを選ぶと値が戻ります。壊れたファイルでは現在の値が残ります。 この段階の見本を開く

小さな練習

data.score > 999 の999を99に変え、得点100を保存してからRで初期化し、そのファイルを読み込むと受け付けないことを確かめます。999に戻します。

このステップ終了時の見本と自分のコードを比べる

自分のゲームに組み込むには

保存・読込のボタンは start() のたびに作らず、一度だけ用意します。保存する項目を自分のゲームに合わせて選び、書き出しと読込の検証を同じ形式・範囲にそろえます。古い読込結果を無視する番号も再開始時に更新します。

見本の状態、入力、更新、描画を自分のゲームの名前に合わせて移します。すでにある start()、update()、draw() に必要な部分を加え、ゲームループは増やしません。やり直すときは追加した状態も初期化してください。

操作：Space:得点、L:レベル、R:初期化、保存・読込ボタン。
