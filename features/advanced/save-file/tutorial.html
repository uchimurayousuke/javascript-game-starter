セーブファイルの書き出しと読み込みを作る

コードの比較の読み方

比較欄は読むための表示です。消す行と追加する行を色と名前で示します。コピーするのは「変更後（コピー用）」の欄です。

− 消す＋ 追加そのまま

この教材では、変更前の script.js 全体を変更後の全体に置き換えます。前のコードを残して重ねて追加しないでください。

始める前に

ひな型をダウンロード（ZIP）

ZIPを展開してできたフォルダーでindex.htmlを開きます。ZIPにはひな型の3ファイルが入っています。

準備と操作を参考に、作業用フォルダーを用意します。この教材ではそのフォルダーの script.js を編集し、保存後に同じフォルダーの index.html を開くか再読み込みします。

ひな型を開く

ステップ 1：Spaceで得点を10増やし、Lでレベルを1増やす

目標

Spaceで得点を10増やし、Lでレベルを1増やす。

予想してみる

Spaceを3回、Lを1回押すと？

答えを確認する

得点30・レベル2です。

小さな作業

上から順に作業します。目印を探し、その下のコードを書きます。

得点と読み込みの状態を覚える

作業用の script.js の先頭近くで、次の目印のすぐ下に追加します。

目印

const ctx = canvas.getContext("2d");

追加するコード

let score, level, message, loadVersion = 0;

let は後で値を変えられる変数を作ります。得点、レベル、案内、読み込みの番号を覚えます。loadVersion は後のステップで古い読み込みを見分けます。

ゲームを初期化する

start() から update() の閉じ波括弧までで、次の範囲を置き換えます。

置き換える範囲

}

function start() {
  score = 0; level = 1; message = ""; loadVersion += 1;

= は右の値を左に入れる代入です。得点 0、レベル 1、案内なしにし、+= 1 で読み込み番号を更新します。

得点とレベルを表示する

draw() の画面を消す行の下で、次の目印のすぐ下に追加します。

目印

  ctx.clearRect(0, 0, canvas.width, canvas.height);

追加するコード

  ctx.fillStyle = "#26334a";
  ctx.font = "28px sans-serif";

  ctx.fillText("レベル: " + level, 200, 190);

文字の色と大きさを決め、+ で文字と数をつなぎます。

操作と結果の案内を表示する

レベルの表示の下で、次の目印のすぐ下に追加します。

目印

追加するコード

キー入力を受け取る

draw() の後、gameLoop() の先頭行の前で、次の目印のすぐ上に追加します。

目印

function gameLoop() {

追加するコード

window.addEventListener("keydown", event => {
  if (event.target && (event.target.tagName === "INPUT" || event.target.tagName === "BUTTON")) return;
  if (event.ctrlKey || event.altKey || event.metaKey || event.isComposing) return;
  if (event.code === "Space") event.preventDefault();

keydown はキーを押したときに起きます。入力欄やボタンを操作中、修飾キーや日本語入力中、繰り返しは除きます。&& は両方、|| はどれか一方という意味です。Space によるスクロールも防ぎます。

Spaceで得点を増やす

キー入力処理の繰り返しを除く行の下で、次の目印のすぐ下に追加します。

目印

  if (event.repeat) return;

追加するコード

  if (event.code === "Space") { score = Math.min(999, score + 10); loadVersion += 1; }

Space なら得点を 10 増やし、Math.min で 999 以下にします。値を変えたので読み込み番号も更新します。

Lでレベルを上げる

Space の判定の下で、次の目印のすぐ下に追加します。

目印

  if (event.code === "Space") { score = Math.min(999, score + 10); loadVersion += 1; }

追加するコード

  if (event.key.toLowerCase() === "l") { level = Math.min(10, level + 1); loadVersion += 1; }

小文字にしたキーが L ならレベルを 1 増やし、10 以下にします。読み込み番号も更新します。

Rで最初から始める

L の判定の下で、次の目印のすぐ下に追加します。

目印

  if (event.key.toLowerCase() === "l") { level = Math.min(10, level + 1); loadVersion += 1; }

追加するコード

  if (event.key.toLowerCase() === "r") start();

R なら start() を呼び、得点とレベルを初期化します。

保存して作業用の index.html を再読み込みし、Space で得点、L でレベルが増え、R で初期値に戻ることを確かめます。

if (event.code === "Space") { score = Math.min(999, score + 10); loadVersion += 1; }

"use strict";

const canvas = document.querySelector("#game-canvas");

function start() {
  score = 0; level = 1; message = ""; loadVersion += 1;
}

function update() {

}

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "#26334a";
  ctx.font = "28px sans-serif";

window.addEventListener("keydown", event => {
  if (event.target && (event.target.tagName === "INPUT" || event.target.tagName === "BUTTON")) return;
  if (event.ctrlKey || event.altKey || event.metaKey || event.isComposing) return;

! は真偽の反転です。データがなければ失敗扱いにします。ここから条件を順に追加します。

オブジェクト以外を拒む

直前に書いた条件の !dataで、次の範囲を置き換えます。

置き換える範囲

!data

置き換えるコード

!data || typeof data !== "object"

|| はどちらか一方です。値がなくてもオブジェクトでなくても拒みます。

配列を拒む

直前に加えた条件の typeof data !== "object"で、次の範囲を置き換えます。

置き換える範囲

typeof data !== "object"

置き換えるコード

typeof data !== "object" || Array.isArray(data)

Array.isArray で配列かを調べ、配列も拒みます。

項目名を検証する

直前に加えた条件の Array.isArray(data)で、次の範囲を置き換えます。

置き換える範囲

Array.isArray(data)

置き換えるコード

Array.isArray(data) || Object.keys(data).sort().join(",") !== "level,score,version"

項目名を並べ替えてつなぎ、level・score・version の 3 つだけか調べます。

バージョンを検証する

項目名の比較の末尾で、次の範囲を置き換えます。

置き換える範囲

Object.keys(data).sort().join(",") !== "level,score,version"

置き換えるコード

Object.keys(data).sort().join(",") !== "level,score,version" || data.version !== 1

バージョンが 1 でなければ拒みます。

得点の整数と下限を検証する

直前に加えた data.version !== 1で、次の範囲を置き換えます。

置き換える範囲

data.version !== 1

置き換えるコード

data.version !== 1 || !Number.isInteger(data.score) || data.score < 0

Number.isInteger で整数かを調べ、得点が整数でないか 0 未満なら拒みます。

得点の上限を検証する

直前に加えた data.score < 0で、次の範囲を置き換えます。

置き換える範囲

data.score < 0

置き換えるコード

data.score < 0 || data.score > 999

得点が 999 を超える場合も拒みます。

レベルの整数と下限を検証する

直前に加えた data.score > 999で、次の範囲を置き換えます。

置き換える範囲

data.score > 999

置き換えるコード

data.score > 999 || !Number.isInteger(data.level) || data.level < 1

レベルが整数でないか 1 未満なら拒みます。

レベルの上限を検証する

直前に加えた data.level < 1で、次の範囲を置き換えます。

置き換える範囲

data.level < 1

置き換えるコード

data.level < 1 || data.level > 10

レベルが 10 を超える場合も拒みます。これですべての検証条件がそろいました。

検証した値を反映する

検証条件の行末の下で、次の目印のすぐ下に追加します。

目印

data.level > 10) throw new Error();

追加するコード

読み込むファイルを選ぶ

const loadInput = document.createElement("input");

ファイルを選ぶ入力欄を作り、JSONを選ぶための種類を指定します。種類の指定だけでは中身が正しいか分からないので、後で内容も確認します。

読み込みの新しさを覚える

const file = loadInput.files[0];
if (!file) return;
const request = ++loadVersion;
loadInput.value = "";

選ばれた最初のファイルを取り出し、未選択なら処理を終えます。++loadVersion で番号を増やし、その番号を request に覚えます。入力欄を空にして、同じファイルをもう一度選べるようにします。

大きさとJSONの形式を調べる

if (file.size > 4096) throw new Error();
const data = JSON.parse(await file.text());
if (request !== loadVersion) return;

ファイルが4096バイトを超えると失敗にします。file.text() の読み込みを待ち、JSON.parse で文字列をデータに戻します。待っている間に別の読み込みや得点・レベルの変更、Rによる初期化があると番号が変わるため、古い結果を使わずに終えます。

形式と値を検証する

if (!data || typeof data !== "object" || Array.isArray(data) || Object.keys(data).sort().join(",") !== "level,score,version" || data.version !== 1 || !Number.isInteger(data.score) || data.score < 0 || data.score > 999 || !Number.isInteger(data.level) || data.level < 1 || data.level > 10) throw new Error();

|| でつないだ条件のどれかに当てはまれば失敗です。データがオブジェクトで、配列ではなく、項目が level・score・version の3つだけか調べます。version は1、得点は整数0〜999、レベルは整数1〜10である必要があります。Number.isInteger で整数かどうかを確かめます。

検証に成功した値だけ反映する

score = data.score; level = data.level; message = "読み込みました";

すべての検証を通った後で初めて得点とレベルに代入します。ファイルが大きすぎる、JSONが壊れている、項目や値が正しくないなどの失敗では catch が「読み込めませんでした」と表示し、元の得点とレベルを保ちます。古い読み込みは失敗の表示も新しい状態に上書きしません。

  score = 0; level = 1; message = ""; loadVersion += 1;

このステップ終了時の見本と自分のコードを比べる

自分のゲームに組み込むには

保存・読込のボタンは start() のたびに作らず、一度だけ用意します。保存する項目を自分のゲームに合わせて選び、書き出しと読込の検証を同じ形式・範囲にそろえます。古い読込結果を無視する番号も再開始時に更新します。

見本の状態、入力、更新、描画を自分のゲームの名前に合わせて移します。すでにある start()、update()、draw() に必要な部分を加え、ゲームループは増やしません。やり直すときは追加した状態も初期化してください。

操作：Space:得点、L:レベル、R:初期化、保存・読込ボタン。
