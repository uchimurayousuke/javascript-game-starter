スプライトアニメーションを作る

コードの比較の読み方

比較欄では消す行、追加する行、そのままの行を色とラベルで示します。変更のない途中の行を省略することがあります。比較欄は読むためのもので、コピーする欄ではありません。

− 消す＋ 追加そのまま

置き換えるときは、赤い行だけを消すのではなく、指定された変更前の範囲すべてをコピー用のコードに置き換えます。そのままの行もコピー用のコードに含まれます。古い関数を残して同じ名前の関数を追加しないでください。

コピーするのは「コピー用」と書かれたコード欄です。比較の記号はコードに入りません。

画像とアニメーションの状態を覚える

作業用の script.js の先頭近くで、次の目印のすぐ下に追加します。

目印

追加するコード

let は後で値を変えられる変数を作ります。画像、横位置、コマ番号、キー、移動中か、アニメーション開始時刻を覚えます。

画像を読み込む関数を用意する

変数の行の下で、次の目印のすぐ下に追加します。

目印

let asset, x, frame, keys, moving, animationStart;

追加するコード

function loadImage(src) {
  const image = new Image();
  const asset = {image, status: "loading"};
  return asset;
}

new Image() は画像を扱うためのものを作ります。asset に画像と読込中の状態をまとめ、return で呼び出し元へ返します。まだ読み込む先を設定していないため、次の作業を続けます。

読込完了を記録する

loadImage() の状態を作る行の下で、次の目印のすぐ下に追加します。

目印

  const asset = {image, status: "loading"};

追加するコード

  image.onload = () => { asset.status = image.naturalWidth > 0 && image.naturalHeight > 0 ? "ready" : "error"; };

onload は読み込みが終わったときに動きます。> はより大きい、&& は両方の条件が必要という意味です。幅と高さが 0 より大きければ ready、そうでなければ error にします。

読込失敗を記録する

onload の行の下で、次の目印のすぐ下に追加します。

目印

  image.onload = () => { asset.status = image.naturalWidth > 0 && image.naturalHeight > 0 ? "ready" : "error"; };

追加するコード

  image.onerror = () => { asset.status = "error"; };

onerror は読み込めなかったときに動き、状態を error にします。

画像の読み込みを始める

onerror の行の下で、次の目印のすぐ下に追加します。

目印

  image.onerror = () => { asset.status = "error"; };

追加するコード

  image.src = src;

src に画像の場所を渡すと読み込みが始まります。

コマ数を調べる関数を作る

loadImage() の閉じ波括弧の下で、次の目印のすぐ下に追加します。

目印

  return asset;
}

追加するコード

function frameCount() {
  if (asset.status !== "ready") return 0;
  const width = asset.image.naturalWidth, height = asset.image.naturalHeight;
  if (width < 64 || width % 64 !== 0 || height !== 64) return 0;
  return width / 64;
}

画像が読込済みでなければ 0 を返します。|| はどれか一つ、% は割った余りです。幅が 64 未満、64 で割り切れない、または高さが 64 でない画像は使いません。横一列のコマ数を幅 ÷ 64 で返します。

画像の状態を表示する

コマ数を求める行の下で、次の目印のすぐ下に追加します。

目印

  const count = frameCount();

追加するコード

  if (asset.status === "loading") ctx.fillText("画像を読み込み中", 220, 100);
  else if (asset.status === "error") ctx.fillText("画像を読み込めません", 220, 100);

=== は同じか、! は真偽の反転です。読込中・失敗・サイズ不正を案内します。正常なら画像の横 frame * 64、縦 0 から 64 × 64 を切り出し、横 x - 32、縦 190 に 64 × 64 で描きます。

コマ番号を表示する

画像の表示分岐の下で、次の目印のすぐ下に追加します。

目印

  else ctx.drawImage(asset.image, frame * 64, 0, 64, 64, x - 32, 190, 64, 64);

追加するコード

使えるコマがあれば番号を表示します。プログラム内は 0 始まりなので、表示には 1 を足します。

読み直しを案内する

コマ番号の表示の下で、次の目印のすぐ下に追加します。

目印

"use strict";

const canvas = document.querySelector("#game-canvas");
const ctx = canvas.getContext("2d");

let asset, x, frame, keys, moving, animationStart;
function loadImage(src) {
  const image = new Image();
  const asset = {image, status: "loading"};
  image.onload = () => { asset.status = image.naturalWidth > 0 && image.naturalHeight > 0 ? "ready" : "error"; };
  image.onerror = () => { asset.status = "error"; };
  image.src = src;
  return asset;
}
function frameCount() {
  if (asset.status !== "ready") return 0;
  const width = asset.image.naturalWidth, height = asset.image.naturalHeight;
  if (width < 64 || width % 64 !== 0 || height !== 64) return 0;
  return width / 64;
}

function start() {
  asset = loadImage("assets/walk-sheet.png"); x = 400; frame = 0; keys = {}; moving = false; animationStart = 0;
}

function update() {

}

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "#26334a"; ctx.font = "24px sans-serif";
  const count = frameCount();
  if (asset.status === "loading") ctx.fillText("画像を読み込み中", 220, 100);
  else if (asset.status === "error") ctx.fillText("画像を読み込めません", 220, 100);
  else if (!count) ctx.fillText("シートの大きさを確認してください", 180, 100);
  else ctx.drawImage(asset.image, frame * 64, 0, 64, 64, x - 32, 190, 64, 64);
  if (count > 0) ctx.fillText("コマ: " + (frame + 1) + " / " + count, 220, 310);
  ctx.fillText("R: 読み直す", 220, 360);
}

window.addEventListener("keydown", event => {
  if (event.key.toLowerCase() === "r" && !event.repeat) { start(); return; }
});

function gameLoop() {
  update();
  draw();
  requestAnimationFrame(gameLoop);
}

ステップ 2：動いている間にコマを進める

目標

動いている間にコマを進める。

小さな作業

上から順に作業します。目印を探し、その下のコードを書きます。

4コマ以上のシートを使う

frameCount() の大きさの判定で、次の範囲を置き換えます。

置き換える範囲

  if (width < 64 || width % 64 !== 0 || height !== 64) return 0;

置き換えるコード

  if (width < 256 || width % 64 !== 0 || height !== 64) return 0;

アニメーション用に幅を最低 256 にします。1 コマ 64 ピクセルなので 4 コマ以上です。幅は 64 の倍数、高さは 64 のままです。

キーから移動方向を求める

update() の中で、次の範囲を置き換えます。

置き換える範囲

function update() {

}

置き換えるコード

function update() {
  const direction = (keys.ArrowRight ? 1 : 0) - (keys.ArrowLeft ? 1 : 0);
}

条件 ? A : B は条件に応じて値を選びます。右だけなら 1、左だけなら -1、両方またはどちらも押していなければ 0 です。

使えるシートがなければ更新しない

方向を求める行の下で、次の目印のすぐ下に追加します。

目印

  const direction = (keys.ArrowRight ? 1 : 0) - (keys.ArrowLeft ? 1 : 0);

追加するコード

  if (frameCount() === 0) { moving = false; frame = 0; return; }

コマ数が 0 なら移動中を解除し、コマ 0 にして更新を終えます。

移動中と停止中を分ける

シートがない場合の判定の下で、次の目印のすぐ下に追加します。

目印

  if (frameCount() === 0) { moving = false; frame = 0; return; }

追加するコード

  if (direction !== 0) {
  } else { moving = false; }

!== は同じではないという意味です。方向が 0 でなければ移動、0 なら移動中を解除します。移動の処理は次に追加します。

移動開始時刻を覚える

移動中の分岐の中で、次の目印のすぐ下に追加します。

目印

  if (direction !== 0) {

追加するコード

    if (!moving) { moving = true; animationStart = performance.now(); }

移動を始めたときだけ現在時刻を記録します。performance.now() はミリ秒です。

人を移動する

移動開始時刻の判定の下で、次の目印のすぐ下に追加します。

目印

    if (!moving) { moving = true; animationStart = performance.now(); }

追加するコード

    x = Math.max(32, Math.min(768, x + direction * 3));

方向に応じて横位置を 3 ずつ動かし、Math.min と Math.max で中心を 32 から 768 に収めます。画像の半分は 32 です。

時間に応じてコマを選ぶ

移動する行の下で、次の目印のすぐ下に追加します。

目印

    x = Math.max(32, Math.min(768, x + direction * 3));

追加するコード

    const count = frameCount();
    if (count > 0) frame = Math.floor((performance.now() - animationStart) / 200) % count;

開始からのミリ秒を 200 で割り、Math.floor で切り捨てます。% count でコマ数の余りにするので、200 ミリ秒ごとに進み、最後の次は 0 に戻ります。

移動の操作を案内する

draw() の操作案内で、次の範囲を置き換えます。

置き換える範囲

  ctx.fillText("R: 読み直す", 220, 360);

置き換えるコード

  ctx.fillText("R: 読み直す / ←→: 移動", 220, 360);

左右キーで移動する案内を加えます。

左右キーの押下を記録する

キー入力処理の R の判定の下で、次の目印のすぐ下に追加します。

目印

  if (event.key.toLowerCase() === "r" && !event.repeat) { start(); return; }

追加するコード

  if (event.key === "ArrowLeft" || event.key === "ArrowRight") { event.preventDefault(); keys[event.key] = true; }

左右キーならスクロールを防ぎ、押下を記録します。

キーを離したことを記録する

"use strict";

const canvas = document.querySelector("#game-canvas");
const ctx = canvas.getContext("2d");

let asset, x, frame, keys, moving, animationStart;
function loadImage(src) {
  const image = new Image();
  const asset = {image, status: "loading"};
  image.onload = () => { asset.status = image.naturalWidth > 0 && image.naturalHeight > 0 ? "ready" : "error"; };
  image.onerror = () => { asset.status = "error"; };
  image.src = src;
  return asset;
}
function frameCount() {
  if (asset.status !== "ready") return 0;
  const width = asset.image.naturalWidth, height = asset.image.naturalHeight;
  if (width < 256 || width % 64 !== 0 || height !== 64) return 0;
  return width / 64;
}

function start() {
  asset = loadImage("assets/walk-sheet.png"); x = 400; frame = 0; keys = {}; moving = false; animationStart = 0;
}

function update() {
  const direction = (keys.ArrowRight ? 1 : 0) - (keys.ArrowLeft ? 1 : 0);
  if (frameCount() === 0) { moving = false; frame = 0; return; }
  if (direction !== 0) {
    if (!moving) { moving = true; animationStart = performance.now(); }
    x = Math.max(32, Math.min(768, x + direction * 3));
    const count = frameCount();
    if (count > 0) frame = Math.floor((performance.now() - animationStart) / 200) % count;
  } else { moving = false; }
}

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "#26334a"; ctx.font = "24px sans-serif";
  const count = frameCount();
  if (asset.status === "loading") ctx.fillText("画像を読み込み中", 220, 100);
  else if (asset.status === "error") ctx.fillText("画像を読み込めません", 220, 100);
  else if (!count) ctx.fillText("シートの大きさを確認してください", 180, 100);
  else ctx.drawImage(asset.image, frame * 64, 0, 64, 64, x - 32, 190, 64, 64);
  if (count > 0) ctx.fillText("コマ: " + (frame + 1) + " / " + count, 220, 310);
  ctx.fillText("R: 読み直す / ←→: 移動", 220, 360);
}

window.addEventListener("keydown", event => {
  if (event.key.toLowerCase() === "r" && !event.repeat) { start(); return; }
  if (event.key === "ArrowLeft" || event.key === "ArrowRight") { event.preventDefault(); keys[event.key] = true; }
});
window.addEventListener("keyup", event => { if (event.key === "ArrowLeft" || event.key === "ArrowRight") keys[event.key] = false; });
window.addEventListener("blur", () => { keys = {}; });

function gameLoop() {
  update();
  draw();
  requestAnimationFrame(gameLoop);
}

start();
gameLoop();
