画像の反転と回転を作る

コードの比較の読み方

比較欄では消す行、追加する行、そのままの行を色とラベルで示します。変更のない途中の行を省略することがあります。比較欄は読むためのもので、コピーする欄ではありません。

− 消す＋ 追加そのまま

置き換えるときは、赤い行だけを消すのではなく、指定された変更前の範囲すべてをコピー用のコードに置き換えます。そのままの行もコピー用のコードに含まれます。古い関数を残して同じ名前の関数を追加しないでください。

コピーするのは「コピー用」と書かれたコード欄です。比較の記号はコードに入りません。

始める前に

画像付きひな型をダウンロード（ZIP）

ZIPを展開してできたフォルダーでindex.htmlを開きます。ZIPにはひな型の3ファイルと画像が入っています。

変更前を探し、変更後のコードに置き換えて保存し、index.html を開き直します。

ステップ 1：画像を中心に置く

目標

画像を中心に置く。

小さな作業

上から順に作業します。目印を探し、その下のコードを書きます。

画像と変形の状態を覚える

作業用の script.js の先頭近くで、次の目印のすぐ下に追加します。

目印

const ctx = canvas.getContext("2d");

追加するコード

let asset, flip, angle;

let は後で値を変えられる変数を作ります。asset は画像と読込状態、flip は反転するか、angle は回転角です。

画像を読み込む関数を用意する

変数の行の下で、次の目印のすぐ下に追加します。

目印

let asset, flip, angle;

追加するコード

function loadImage(src) {
  const image = new Image();
  const asset = {image, status: "loading"};
  return asset;
}

new Image() は画像を扱うためのものを作ります。asset に画像と読込中の状態をまとめ、return で呼び出し元へ返します。まだ読み込む先を設定していないため、次の作業を続けます。

読込完了を記録する

loadImage() の状態を作る行の下で、次の目印のすぐ下に追加します。

目印

  const asset = {image, status: "loading"};

追加するコード

  image.onload = () => { asset.status = image.naturalWidth > 0 && image.naturalHeight > 0 ? "ready" : "error"; };

onload は読み込みが終わったときに動きます。> はより大きい、&& は両方の条件が必要という意味です。幅と高さが 0 より大きければ ready、そうでなければ error にします。

読込失敗を記録する

onload の行の下で、次の目印のすぐ下に追加します。

目印

  image.onload = () => { asset.status = image.naturalWidth > 0 && image.naturalHeight > 0 ? "ready" : "error"; };

追加するコード

  image.onerror = () => { asset.status = "error"; };

onerror は読み込めなかったときに動き、状態を error にします。

画像の読み込みを始める

onerror の行の下で、次の目印のすぐ下に追加します。

目印

  image.onerror = () => { asset.status = "error"; };

追加するコード

  image.src = src;

src に画像の場所を渡すと読み込みが始まります。

画像と変形を初期化する

start() から update() の閉じ波括弧までで、次の範囲を置き換えます。

置き換える範囲

}

function update() {
}

置き換えるコード

function start() {
  asset = loadImage("assets/player-blue.png"); flip = false; angle = 0;
}

function update() {

}

= は右の値を左に入れる代入です。画像付きひな型の ZIP にある assets を 3 ファイルと一緒に置き、assets/player-blue.png を読み込みます。反転なし、角度 0 で始めます。

画像か読込状態を表示する

draw() の画面を消す行の下で、次の目印のすぐ下に追加します。

目印

  ctx.clearRect(0, 0, canvas.width, canvas.height);

追加するコード

  ctx.fillStyle = "#26334a"; ctx.font = "24px sans-serif";
  if (asset.status === "ready") {
    ctx.drawImage(asset.image, 368, 193, 64, 64);
  } else ctx.fillText(asset.status === "error" ? "画像を読み込めません" : "読み込み中", 180, 100);

if は条件が成り立つときに実行し、=== は同じかの比較です。読込済みなら幅・高さ 64 の画像を左 368、上 193 に描きます。中心は (400, 225) です。失敗時と読込中は文字を表示します。

中心に印を描く

画像の表示分岐の下で、次の目印のすぐ下に追加します。

目印

  } else ctx.fillText(asset.status === "error" ? "画像を読み込めません" : "読み込み中", 180, 100);

追加するコード

  ctx.fillStyle = "#bd422f"; ctx.fillRect(397, 222, 6, 6);

幅・高さ 6 の赤い四角の中心が (400, 225) です。

中心と操作を案内する

中心の印の下で、次の目印のすぐ下に追加します。

目印

  ctx.fillStyle = "#bd422f"; ctx.fillRect(397, 222, 6, 6);

追加するコード

  ctx.fillStyle = "#26334a"; ctx.fillText("中心 (400,225) / R: 再開", 80, 360);

中心座標と R で再開する操作を表示します。

const canvas = document.querySelector("#game-canvas");
const ctx = canvas.getContext("2d");

let asset, flip, angle;
function loadImage(src) {
  const image = new Image();
  const asset = {image, status: "loading"};
  image.onload = () => { asset.status = image.naturalWidth > 0 && image.naturalHeight > 0 ? "ready" : "error"; };
  image.onerror = () => { asset.status = "error"; };
  image.src = src;
  return asset;
}

function start() {
  asset = loadImage("assets/player-blue.png"); flip = false; angle = 0;
}

function update() {

}

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "#26334a"; ctx.font = "24px sans-serif";
  if (asset.status === "ready") {
    ctx.drawImage(asset.image, 368, 193, 64, 64);
  } else ctx.fillText(asset.status === "error" ? "画像を読み込めません" : "読み込み中", 180, 100);
  ctx.fillStyle = "#bd422f"; ctx.fillRect(397, 222, 6, 6);
  ctx.fillStyle = "#26334a"; ctx.fillText("中心 (400,225) / R: 再開", 80, 360);

  if (event.repeat) return;

  update();
  draw();

ステップ 2：左右を反転する

目標

左右を反転する。

小さな作業

上から順に作業します。目印を探し、その下のコードを書きます。

画像を中心基準で描く

画像を描く行で、次の範囲を置き換えます。

置き換える範囲

    ctx.drawImage(asset.image, 368, 193, 64, 64);

置き換えるコード

    ctx.save(); ctx.translate(400, 225);
    ctx.drawImage(asset.image, -32, -32, 64, 64);
    ctx.restore();

save() で描画設定を保存し、translate で原点を (400, 225) に移します。画像を原点から左上へ半分の 32 ずらして中心を合わせ、restore() で設定を戻します。

反転を描画に反映する

translate の行の下で、次の目印のすぐ下に追加します。

目印

    ctx.save(); ctx.translate(400, 225);

追加するコード

    ctx.scale(flip ? -1 : 1, 1);

条件 ? A : B は条件に応じて A または B を選びます。flip が真なら横方向を -1 倍、偽なら 1 倍にします。縦は 1 倍のままです。

反転を案内する

draw() の操作案内で、次の範囲を置き換えます。

置き換える範囲

  ctx.fillStyle = "#26334a"; ctx.fillText("中心 (400,225) / R: 再開", 80, 360);

置き換えるコード

  ctx.fillStyle = "#26334a"; ctx.fillText("中心 (400,225) / R: 再開 / F: 反転", 80, 360);

F で反転を切り替える案内を加えます。

Fで反転を切り替える

キー入力処理の R の判定と閉じ括弧の間で、次の範囲を置き換えます。

置き換える範囲

  if (event.key.toLowerCase() === "r") { start(); return; }

});

置き換えるコード

  if (event.key.toLowerCase() === "r") { start(); return; }
  if (event.key.toLowerCase() === "f") flip = !flip;
});

! は真偽の反転です。F を押すたび flip が切り替わります。

保存して再読み込みし、F を押すと赤い印を中心に左右が反転することを確かめます。

小さな作業

translate の行の下で、次の目印のすぐ下に追加します。

目印

    ctx.save(); ctx.translate(400, 225);

    ctx.rotate(angle);

回転を案内する

draw() の操作案内で、次の範囲を置き換えます。

  ctx.fillStyle = "#26334a"; ctx.fillText("中心 (400,225) / R: 再開 / F: 反転 / A: 回転", 80, 360);

F の判定の下で、次の目印のすぐ下に追加します。

目印
