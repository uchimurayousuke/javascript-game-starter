カメラ追従と座標を作る

コードの比較の読み方

比較欄では消す行、追加する行、そのままの行を色とラベルで示します。変更のない途中の行を省略することがあります。比較欄は読むためのもので、コピーする欄ではありません。

− 消す＋ 追加そのまま

置き換えるときは、赤い行だけを消すのではなく、指定された変更前の範囲すべてをコピー用のコードに置き換えます。そのままの行もコピー用のコードに含まれます。古い関数を残して同じ名前の関数を追加しないでください。

コピーするのは「コピー用」と書かれたコード欄です。比較の記号はコードに入りません。

変更前を探し、変更後のコードに置き換えて保存し、index.html を開き直します。

ステップ 1：世界の中で人を動かす

目標

世界の中で人を動かす。

小さな作業

上から順に作業します。目印を探し、その下のコードを書きます。

世界の大きさと状態を用意する

作業用の script.js の先頭近くで、次の目印のすぐ下に追加します。

目印

const ctx = canvas.getContext("2d");

追加するコード

const worldWidth = 2000, worldHeight = 900;
let player, camera, keys, clicked;

const で世界の幅 2000・高さ 900 を決め、let でプレイヤー、カメラ、キー、クリック位置を覚えます。画面は幅 800・高さ 450 です。

開始位置を設定する

start() の中で、次の目印のすぐ下に追加します。

目印

function start() {

追加するコード

  player = {x: 400, y: 225}; camera = {x: 0, y: 0}; keys = {}; clicked = null;

= は右の値を左に入れる代入です。人の中心を (400, 225)、カメラ左上を (0, 0) にし、キーとクリックの記録を空にします。座標は左上を原点に右と下へ増えます。

左右に移動する

update() の中で、次の目印のすぐ下に追加します。

目印

function update() {

追加するコード

  player.x += ((keys.ArrowRight ? 1 : 0) - (keys.ArrowLeft ? 1 : 0)) * 4;

条件 ? A : B は条件に応じて A または B を選びます。右だけなら 4 増え、左だけなら 4 減ります。+= は今の値に足す書き方です。

上下に移動する

左右移動の行の下で、次の目印のすぐ下に追加します。

目印

  player.x += ((keys.ArrowRight ? 1 : 0) - (keys.ArrowLeft ? 1 : 0)) * 4;

追加するコード

  player.y += ((keys.ArrowDown ? 1 : 0) - (keys.ArrowUp ? 1 : 0)) * 4;

下だけなら縦位置を 4 増やし、上だけなら 4 減らします。

人を世界の中に収める

上下移動の行の下で、次の目印のすぐ下に追加します。

目印

  player.y += ((keys.ArrowDown ? 1 : 0) - (keys.ArrowUp ? 1 : 0)) * 4;

追加するコード

  player.x = Math.max(16, Math.min(worldWidth - 16, player.x));
  player.y = Math.max(16, Math.min(worldHeight - 16, player.y));

Math.min と Math.max で中心を世界の端から 16 以上内側に収めます。人の四角の半分が 16 なので、端からはみ出しません。

画面の背景を描く

draw() の画面を消す行の下で、次の目印のすぐ下に追加します。

目印

  ctx.clearRect(0, 0, canvas.width, canvas.height);

追加するコード

  ctx.fillStyle = "#dcecca"; ctx.fillRect(0, 0, 800, 450);
  ctx.fillStyle = "#7c9c66";

画面全体を塗り、次に描く線の色を決めます。

世界の縦線を描く

線の色の設定の下で、次の目印のすぐ下に追加します。

目印

  ctx.fillStyle = "#7c9c66";

追加するコード

  for (let x = 0; x <= worldWidth; x += 200) ctx.fillRect(x - camera.x, -camera.y, 2, worldHeight);

for で世界の横座標を 200 ずつ増やし、縦線を描きます。描画位置は世界の座標からカメラ左上を引いた画面座標です。<= は以下です。

世界の横線を描く

縦線を描く行の下で、次の目印のすぐ下に追加します。

目印

  for (let x = 0; x <= worldWidth; x += 200) ctx.fillRect(x - camera.x, -camera.y, 2, worldHeight);

追加するコード

  for (let y = 0; y <= worldHeight; y += 150) ctx.fillRect(-camera.x, y - camera.y, worldWidth, 2);

縦座標を 150 ずつ増やして横線を描きます。ここでもカメラの位置を引きます。

人を画面に描く

横線を描く行の下で、次の目印のすぐ下に追加します。

目印

  for (let y = 0; y <= worldHeight; y += 150) ctx.fillRect(-camera.x, y - camera.y, worldWidth, 2);

追加するコード

  ctx.fillStyle = "#397ab4"; ctx.fillRect(player.x - camera.x - 16, player.y - camera.y - 16, 32, 32);

世界の人の位置からカメラ位置を引いて画面位置に変え、幅と高さ 32 の四角の中心を合わせます。例えば人の x が 600、カメラの x が 200 なら画面の中心 x は 400 です。

座標と操作を表示する

人を描く行の下で、次の目印のすぐ下に追加します。

目印

  ctx.fillStyle = "#397ab4"; ctx.fillRect(player.x - camera.x - 16, player.y - camera.y - 16, 32, 32);

追加するコード

  ctx.fillStyle = "#26334a"; ctx.font = "20px sans-serif";
  ctx.fillText("人の中心: (" + player.x + ", " + player.y + ")", 20, 35);
  ctx.fillText("カメラ左上: (" + camera.x + ", " + camera.y + ")", 20, 65);
  ctx.fillText("矢印: 移動 / R: 再開", 20, 420);

人の世界座標、カメラ左上の世界座標、操作案内を表示します。

キー入力を受け取る

draw() の後、gameLoop() の先頭行の前で、次の目印のすぐ上に追加します。

目印

function gameLoop() {

追加するコード

window.addEventListener("keydown", event => {
  if (event.key.toLowerCase() === "r" && !event.repeat) { start(); return; }
});

keydown はキーを押したときに起きます。小文字にしたキーが R で繰り返しでなければ初期化します。&& は両方の条件、! は真偽の反転です。

矢印キーの押下を記録する

R の判定の下で、次の目印のすぐ下に追加します。

目印

  if (event.key.toLowerCase() === "r" && !event.repeat) { start(); return; }

追加するコード

  if (["ArrowLeft", "ArrowRight", "ArrowUp", "ArrowDown"].includes(event.key)) { event.preventDefault(); keys[event.key] = true; }

includes は一覧にキーがあるか調べます。矢印キーならスクロールを防ぎ、押下を記録します。

キーを離したことを記録する

keydown の処理の後で、次の目印のすぐ下に追加します。

目印

  if (["ArrowLeft", "ArrowRight", "ArrowUp", "ArrowDown"].includes(event.key)) { event.preventDefault(); keys[event.key] = true; }
});

追加するコード

window.addEventListener("keyup", event => { keys[event.key] = false; });

keyup はキーを離したときに起き、記録を false にします。

画面から離れたら入力を消す

keyup の処理の下で、次の目印のすぐ下に追加します。

目印

window.addEventListener("keyup", event => { keys[event.key] = false; });

追加するコード

window.addEventListener("blur", () => { keys = {}; });

別の画面へ移るとキーの記録を空にし、押されたまま残るのを防ぎます。

保存して作業用の index.html を再読み込みし、矢印キーで人が移動し、カメラ左上が (0, 0) のままであることを確かめます。追従は次に作ります。

"use strict";

const canvas = document.querySelector("#game-canvas");
const ctx = canvas.getContext("2d");

const worldWidth = 2000, worldHeight = 900;
let player, camera, keys, clicked;

function start() {
  player = {x: 400, y: 225}; camera = {x: 0, y: 0}; keys = {}; clicked = null;
}

function update() {
  player.x += ((keys.ArrowRight ? 1 : 0) - (keys.ArrowLeft ? 1 : 0)) * 4;
  player.y += ((keys.ArrowDown ? 1 : 0) - (keys.ArrowUp ? 1 : 0)) * 4;
  player.x = Math.max(16, Math.min(worldWidth - 16, player.x));
  player.y = Math.max(16, Math.min(worldHeight - 16, player.y));

}

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "#dcecca"; ctx.fillRect(0, 0, 800, 450);
  ctx.fillStyle = "#7c9c66";
  for (let x = 0; x <= worldWidth; x += 200) ctx.fillRect(x - camera.x, -camera.y, 2, worldHeight);
  for (let y = 0; y <= worldHeight; y += 150) ctx.fillRect(-camera.x, y - camera.y, worldWidth, 2);
  ctx.fillStyle = "#397ab4"; ctx.fillRect(player.x - camera.x - 16, player.y - camera.y - 16, 32, 32);
  ctx.fillStyle = "#26334a"; ctx.font = "20px sans-serif";
  ctx.fillText("人の中心: (" + player.x + ", " + player.y + ")", 20, 35);
  ctx.fillText("カメラ左上: (" + camera.x + ", " + camera.y + ")", 20, 65);
  ctx.fillText("矢印: 移動 / R: 再開", 20, 420);
}

window.addEventListener("keydown", event => {
  if (event.key.toLowerCase() === "r" && !event.repeat) { start(); return; }
  if (["ArrowLeft", "ArrowRight", "ArrowUp", "ArrowDown"].includes(event.key)) { event.preventDefault(); keys[event.key] = true; }
});
window.addEventListener("keyup", event => { keys[event.key] = false; });
window.addEventListener("blur", () => { keys = {}; });

function gameLoop() {
  update();
  draw();
  requestAnimationFrame(gameLoop);
}

start();
gameLoop();

カメラを追従させる。

カメラを横に追従させる

目印

  player.y = Math.max(16, Math.min(worldHeight - 16, player.y));

  camera.x = Math.max(0, Math.min(worldWidth - 800, player.x - 400));

  camera.y = Math.max(0, Math.min(worldHeight - 450, player.y - 225));

人の縦位置から画面高さの半分 225 を引き、カメラの縦位置を 0 から 450 に収めます。

"use strict";

const canvas = document.querySelector("#game-canvas");
const ctx = canvas.getContext("2d");

const worldWidth = 2000, worldHeight = 900;
let player, camera, keys, clicked;

function start() {
  player = {x: 400, y: 225}; camera = {x: 0, y: 0}; keys = {}; clicked = null;
}

function update() {
  player.x += ((keys.ArrowRight ? 1 : 0) - (keys.ArrowLeft ? 1 : 0)) * 4;
  player.y += ((keys.ArrowDown ? 1 : 0) - (keys.ArrowUp ? 1 : 0)) * 4;
  player.x = Math.max(16, Math.min(worldWidth - 16, player.x));
  player.y = Math.max(16, Math.min(worldHeight - 16, player.y));
  camera.x = Math.max(0, Math.min(worldWidth - 800, player.x - 400));
  camera.y = Math.max(0, Math.min(worldHeight - 450, player.y - 225));

}

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "#dcecca"; ctx.fillRect(0, 0, 800, 450);
  ctx.fillStyle = "#7c9c66";
  for (let x = 0; x <= worldWidth; x += 200) ctx.fillRect(x - camera.x, -camera.y, 2, worldHeight);
  for (let y = 0; y <= worldHeight; y += 150) ctx.fillRect(-camera.x, y - camera.y, worldWidth, 2);
  ctx.fillStyle = "#397ab4"; ctx.fillRect(player.x - camera.x - 16, player.y - camera.y - 16, 32, 32);
  ctx.fillStyle = "#26334a"; ctx.font = "20px sans-serif";
  ctx.fillText("人の中心: (" + player.x + ", " + player.y + ")", 20, 35);
  ctx.fillText("カメラ左上: (" + camera.x + ", " + camera.y + ")", 20, 65);
  ctx.fillText("矢印: 移動 / R: 再開", 20, 420);
}

window.addEventListener("keydown", event => {
  if (event.key.toLowerCase() === "r" && !event.repeat) { start(); return; }
  if (["ArrowLeft", "ArrowRight", "ArrowUp", "ArrowDown"].includes(event.key)) { event.preventDefault(); keys[event.key] = true; }
});
window.addEventListener("keyup", event => { keys[event.key] = false; });
window.addEventListener("blur", () => { keys = {}; });

function gameLoop() {
  update();
  draw();
  requestAnimationFrame(gameLoop);
}

start();
gameLoop();
