# JavaScript ゲーム制作ひな型

HTML・CSS・JavaScript を学ぶ人が、自分のゲームを作り始めるための最小限のひな型です。`index.html` をブラウザで開くと、空のゲーム画面が表示されます。インストールやビルドは必要ありません。

## 用意しているもの

- 800 × 450 の Canvas（画面幅に合わせて縮小表示）
- 最初に1回呼ばれる `start()`
- 毎フレーム呼ばれる `update()` と `draw()`
- `requestAnimationFrame` を使うゲームループ

## 自分で作るもの

ルートのひな型には、キャラクター、操作、得点、勝敗条件、タイトル画面、画像や音など、ゲーム固有の要素は入れていません。必要なものを少しずつ追加してください。

## ルートのファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | Canvas を配置し、CSS と JavaScript を読み込む |
| `style.css` | Canvas の表示位置と大きさを決める |
| `script.js` | `start()`・`update()`・`draw()` にゲームの処理を書く |

まずは `script.js` の `draw()` に図形を描き、次に `update()` でその位置を変えると、動きを確認できます。変更したらブラウザを再読み込みしてください。

## ステップ別チュートリアル

[コインキャッチを作るチュートリアル](tutorial/README.md)を追加しています。描画 → 更新 → 入力 → 当たり判定 → クリアと再挑戦の5段階で、遊べる小さなゲームを作ります。

まずは [STEP 01 の index.html](tutorial/01-draw/index.html) を自分のパソコンのブラウザで開いてください。[完成版](tutorial/05-game/index.html)から試すこともできます。GitHub 上ではファイルの内容が表示されるため、リポジトリをダウンロードまたはクローンして開きます。

各ステップのフォルダーには、その段階の `index.html`・`style.css`・`script.js` がそろっています。依存ライブラリ、インストール、ビルド、開発用サーバーは不要です。
