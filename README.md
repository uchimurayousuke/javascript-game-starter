# JavaScript ゲーム制作スターター

HTML・CSS・JavaScript を学び始めた人が、ブラウザで動くゲームを作るためのひな型です。インストールやビルドは必要ありません。最初から遊べる「ターゲットを押す」サンプルを、自分の作品へ少しずつ改造できます。

## まず動かす

1. このリポジトリをダウンロードするか、クローンします。
2. `index.html` をブラウザで開きます。
3. 「ゲーム開始」を押して、ターゲットを押してみます。

## このひな型で用意する範囲

| 用意するもの | 内容 |
| --- | --- |
| ゲームの土台 | 開始・プレイ・結果の画面、再挑戦ボタン |
| 基本の処理 | クリック入力、得点、制限時間、画面の切り替え |
| 見た目 | スマートフォンでも使えるレイアウトと、変更しやすい色の設定 |
| 学習の手がかり | 編集する場所を示すコメントと、この README |

ゲームのテーマ、勝敗条件、難易度、画像や音、追加の操作方法は、作品ごとに自分で考えて実装する範囲です。最初の版は DOM を使ったクリックゲームに絞ります。別ジャンルに共通する仕組みは、実際に必要になった段階で追加します。

## ファイル構成

```text
.
├── index.html  画面に表示する文章と部品
├── style.css   色・配置・ターゲットの見た目
├── script.js   得点・時間・ゲームのルール
└── README.md   使い方と設計方針
```

## 改造の進め方

1. `index.html` のタイトルや説明文を自分のゲームに変える。
2. `style.css` の先頭にある3つの色を変える。
3. `script.js` の `GAME_SECONDS` と `POINTS_PER_HIT` を変える。
4. `hitTarget()` や `moveTarget()` を編集し、新しいルールを作る。

変更したらブラウザを再読み込みして確認します。JavaScript のエラーが出た場合は、ブラウザの開発者ツールの「コンソール」を見てください。
